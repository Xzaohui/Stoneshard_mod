# 洄珥 FX-CV6｜第七批两种表情

本目录保存两张全身透明像素概念。作者已实际看母图、每张原稿、透明选稿及浅深背景，现为独审待核候选；最终准入以 FINAL_STATUS.json 绑定的独审文件为准。

## 内容
- E1 忧看雨势：她先看低云，衡量今日是否该下谷，担心雨水会改变退路。
- E2 闻响警觉：若现场听见上游闷响，她立刻注意声源，准备提醒人往坡上避水。

## 生成与来源
使用 builtin imagegen，每表情1首稿，未使用硬错修订。prompts/存调用前逐字真实prompt与完整参数；raw/存全部原输出及含完整data URL的原始返回对象；generation-log.json绑定输入母图、输出路径与SHA。sources/source_index.json列角色卡、台本、母图、母图manifest、风格与brief快照。未借用他人脸或身体。

## 图像处理与限制
selected/为原PNG逐字节复制，保留所有RGBA，包括alpha0隐藏RGB；浅深合成检查未发现可见污染。没有阈值化、画脸、拉伸、裁切、量化或调色。中文浅深板按原尺寸放置，不改人物本体。

## 作者观察
- E1仍仰视画面左上，但内眉忧聚、唇闭合下收，形成忧看雨势；画面左的右手收近腰旁、手指自然垂弯；左手扶原背带。红褐发、青灰短褂、麻色翻袖、棕裤、双靴草绳保留。
- E2眉更平直警醒、眼睑较开、短促张口提醒，与E1闭唇忧虑可辨；头转为较低的左侧听向。右手仍低于腰的近旁，未高举劝停。画面右唯一探路长杆上下端完整，左手仍扶背带而非拔杆。
- 两幅都稳定站立，没有云雨、洪水、路标、第二人物、救援或寻回结果；不宣布DT06完成、位置公开或强制归返。E2头位回平幅度克制，不以臆定角度强制返工。

本人存活、在场、愿谈且有有限见闻才适用。两图为独立可逆表情，不是连续结局；不改变原卡、任务、关系或结果。原生游戏网格、part/frame/mask/origin、装备、动画及runtime均未验证。尚未封包、上传或git提交。
