## 实际复现

运行：`python Assets/RedrawStudies/20261013/cloth_barrel/postprocess.py`（仓库根目录）。使用环境已存在的Pillow、NumPy；不安装依赖。脚本从保留的imagegen体积稿读取最大alpha连通主体，128阈值二值化，最近邻采样至24×25、14色最近色映射，保存诚实的初始中间稿，再按有注释的四组确定像素形状重构（主体、铁箍、短布盖、绳结）。生成native、8×、QA背景和逐像素修改日志。生成模型本身不承诺确定性重生；保留原输出及SHA供完整复现后处理。

- `pixel_edits.json`：初始稿到候选稿的每个修改像素，坐标、旧RGBA、新RGBA。
- `QA.json`：透明度、尺寸、颜色预算、画布边界自动检查。
- `manifest.json`：源文件、生成文件、后处理输出和脚本SHA256。

## 已看与未验

已实际查看旧场景、目标裁切、原版桶、新生成稿、同倍率对照和三背景候选。布与木铁的区分清楚；最终布摆明显短于初始稿，不以木纹或杂点支撑识别。绳结在1×下是非常小的识别簇，不代表可读封签或机械密封。相较历史原桶，新桶仍更规整、更亮，后续应在实际场景光照中复核，而不是宣称完全匹配正式资产。
