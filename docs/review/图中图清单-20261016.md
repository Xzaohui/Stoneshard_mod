# 图中图清单（code/c1-a3 @ d7dc38b7，只读审查）

规则（用户）：扩展地图 = 外扩外围范围；嵌套区域只能是建筑/副本/地牢，经门或过场进入；不能把一张地图嵌在现有地图里。

范围：src/EmbersAndOaths 里所有 `r_eao_*` 房间（NightRooms / N2Quest / SceneAssembly / FieldQuest / NativeRooms 的房间构建，以及 *Quest.cs、EmbersAndOathsMod.cs 的 Door、`Codes/night_controller_step.gml` / `annex_entry_spawn.gml` 的入口生成）。共 10 个房间。

共同事实：10 个房间都是复制原版 `r_DockStore1floor`/`r_DockStore2floor` 再改尺寸（如 NightRooms.cs:32-34、FieldQuest.cs:38-40）。src 里没有任何代码给它们分配世界地图格（`scr_globaltile_*`、globalmap 只出现在 F8 测试传送里，不涉及这些房间）。所以它们都不在世界地图上，只能从现有地图里的门进入，不存在"外扩"的房间。门生成在哪张原版地图里，就决定了它算建筑嵌套还是图中图。

## 违规与存疑：证据与整改

### V1 r_eao_n1_yard（图中图）
- 证据：src/EmbersAndOaths/Codes/night_controller_step.gml:48-66。门只在商队停驻（`scr_caravanPositionGetDistance()==0`）时出现，位置是玩家坐标 +2..+5 格的任意可走格。门的目标见 NightQuest.cs:164 `Door("entry",NightRooms.Yard,…"旧渡口堤道")`；房间是露天断桥外景，见 NightRooms.cs:33。
- 问题：一张露天外景地图，通过野外地图中间凭空出现的门嵌进去了。
- 整改：二选一。把断桥做成世界地图外围新增的格，走原版边缘通行；或者入口改成野外里固定的建筑或洞口（如渡口小屋、堤下涵洞），门后只接钟房、暗渠这类室内或地牢。

### V2 r_eao_n2_sites（图中图）
- 证据：night_controller_step.gml:67-79，同样在商队所在的地图里随机格生成 `o_eao_n2_entry`；目标见 SceneAssembly.cs:116 `Door("o_eao_n2_entry",Sites,…"灰堤外院")`；52×38 露天外院，三座建筑见 layout.json `buildings`。
- 整改：把灰堤外院做成外围外扩的地图格，从世界地图边缘走进去；它下面的三座建筑门保留。

### V3 r_eao_fx_quarry（图中图）
- 证据：night_controller_step.gml:33-46，`o_eao_fx_entry` 生成在 r_Brynn_* 城区里玩家坐标 +7..+8、+2..+9 格处；目标见 FieldQuest.cs:261 `Door("fx_entry",Quarry,…"城外石场小径")`，返回见 :262 `r_Brynn_SW`；房间是露天采石场（FieldQuest.cs:39「废弃石场」）。
- 整改：把石场做成布林城外的外扩格，从城区边缘或城门出去；也可以改成城外坑道或矿洞（门后是地牢），不再在城区地面上凭空放门。

### Q1 r_eao_n2_camp（存疑）
- 证据：layout.json `buildings[0]` 门「雇工棚」→ r_eao_n2_camp；N2Quest.cs:58 标题「灰堤雇工棚」，美术源 r01_camp（露天营地加水渠）。
- 判断：入口是建筑门，形式合规；但门后是一张露天地图，等于在外院里又嵌了一张外景。
- 整改：把 camp 改成棚屋室内（铺位、灶台），露天部分并入 sites 外院；或者随 V2 一起外扩。

### Q2 r_eao_n2_winch（存疑）
- 证据：layout.json `buildings[1]` 门「绞盘作业棚」→ r_eao_n2_winch；N2Quest.cs:58 标题「塌堤」；N2Quest.cs:306 camp 门 `to_winch`「去塌堤」。
- 判断：从一扇作业棚门走进去，却是露天塌堤，属于外景嵌套。
- 整改：二选一。把绞盘棚做成室内，塌堤并入 sites 或外扩格；或者在外扩格的边缘接到塌堤。

## 附注
- 各 `home` 门（NightQuest.cs:165、N2Quest.cs:305、SceneAssembly.cs:117）都退回 `EAO_N1_origin_room`，也就是进入前的原地图。这说明以上房间都没有自己的世界地图坐标。
- 本审查只读，没有改动代码；没有使用 codex 或 glm 做初筛，房间只有 10 个，都是逐条人工核对。
