## 显式处理记录
1. 内置 image_gen 读取旧整板与原版簇参照，重绘唯一左一坐姿，删去分指、靴带、细衣褶；输出原样保留。
2. 新生成稿alpha≥128取bbox，最近邻采样到20×29，放入35×44画布(7,9)。按脚底 y=37锁定；无抖动，透明alpha只0/255。
3. 采用脚本明确列出的16色目标调色板，最近色映射。实际成稿用14色。
4. 对初稿作完整原生簇重构，逐行字符网格写在 `build.py`，逐像素before/after写入 `pixel_edits.json`（465处变更）。并非“只减色”或声称保留细脸。面部主动退化为单眼/皮肤/灰胡须块；旧细眉眼没有被自动保留。披肩封闭块、橄榄胸腹块、两手暖色块、膝裤块、靴底以及后排凳腿均被重新排布。
5. 膝下中央透明缝、左凳旁间隙及后排暖棕凳腿显式检查。脚底两侧同y，但不证明步态或起身动力学。
