## 不能混淆的规格

生图工具没有实际返回原生尺寸。头像v1/v2原始PNG均为1079×1458；地图v1为1119×1406、v2为1119×1405。真实源图色数/alpha逐项实测见qa，不根据参考拼图上的标签推断。

目标尺寸文件由 `export_candidates.py` 进行整画布最近邻缩放、可见像素无抖动median-cut量化、alpha阈值128导出；没有用Python画人物、改五官或伪造原生像素网格。32/20只是本批临时颜色预算，不是全项目永久调色板；量化后有近似深色，色数合格不代表色阶已经手工设计。

技术尺寸、色数、二值alpha检查通过，只表示派生文件满足文件规格。头像仍是风格候选，地图在视觉验收失败，两者都不能宣称由工具原生逐像素制作完成。
