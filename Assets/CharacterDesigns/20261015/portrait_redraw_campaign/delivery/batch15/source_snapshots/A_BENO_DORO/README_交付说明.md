## 交付与边界

- 四张独立 PNG 均为 74×100、RGBA、二值 alpha，逐字节复制独立 QA 终选；各图可见 RGB 数以 selected_delivery_manifest.json 为准，均不超过 32 色。最多 32 可见 RGB 色只是临时工作预算，不代表原生色板或手工像素验收。
- 中文手机总览每人含 1× 原尺寸与 4× 整数最近邻。只排版，不补画、改色或平滑插值。展示区域逐像素核对，最终总览和四张 PNG 均实际查看。
- 本批共 8 次成功内置 imagegen：每人初稿加一次集中修订；未开启第三稿。完整保留 8 份 raw、11 份派生候选。贝诺、多罗、古岚的 v2 safe 均是同一 v2 raw 的等比最近邻留边导出，没有新增生图。贝诺与多罗另保留参数校验拒绝记录，该失败调用没有生成图像。
- 贝诺与多罗：整幅 raw 以单一名义等比系数 NEAREST 缩放，普通导出放入 74×100，safe 导出放入 72×98 区域，整数尺寸四舍五入后居中。safe 实际尺寸为 72×97，偏移 (1,1)。
- 菲勒与古岚：整幅 raw 按单一等比系数、逆映射像素中心最近邻采样到透明画布。菲勒两版与古岚普通版 fit region 为 74×100；古岚 safe 为 72×98，浮点居中偏移。精确值逐项记录于便携复现报告。这与整数尺寸缩放的采样实现不同，不混称同一算法。
- 采样后以阈值 128 二值化 alpha。贝诺与多罗用可见采样 RGB 生成 32 色 MEDIANCUT 调色板；菲勒与古岚使用 MAXCOVERAGE。全部无抖动映射，透明 RGB 归零。没有脚本补画人物几何或五官。
- safe 留边只改善目标画布安全边，不补画、不恢复图外未知内容，也不把技术检查当成原始构图的普遍完整保证。
- 精确参数与完整工具返回保留；模型、seed、quality 等未暴露字段不编造。生图本身不承诺确定性复现；逐字节复现仅针对已存 raw 至派生候选。
- 本批均为带备注的冻结头像候选，非原生手工逐像素终稿，不代表用户审美终审或游戏验收；未集成游戏、未实机验证。
