## 修正与方法

G1初稿较大，弃用于最终序列；以G2尺度重生G1 v2，未对单帧主体另做拉伸缩小。E2初稿握手张开，以内置imagegen局部闭手修正v2。G2空手白色杂点及周围细碎残边用授权像素脚本局部清除透明，保留手指轮廓，原始PNG仍保留。共六个生成原稿，最终四个新姿态。

所有最终新姿态原始画布1254²，统一最近邻转换1536²，比例因子1536/1254，不按各帧包围盒缩放/居中。侧撤记录刚性平移以登记左侧支撑脚；并非将静态身体平移冒充新姿态。支撑脚与骨盆投影为人工观察坐标，约±16px，不是物理质心或引擎骨点；连续足轨迹未完成。

木剑直接复用attack_v2_geometry唯一标准剑层，SHA应相同。局部握点(64,80)、刃基(64,140)、刃尖(64,460)，解析刃长320px；只作刚性旋转和平移，8px最近邻轮廓采样会有栅格边缘误差。顺序身体→剑→手前景，手掌覆盖握柄；没有重新生成每帧不同长短的剑。头巾、臂、分片衣摆与剑在最终帧逐张检查。

交付PNG在alpha=0处将RGB归零。六帧层重组均与最终PNG逐像素一致，见recomposition_checks.json。结构检查不代替独立视觉审查。
