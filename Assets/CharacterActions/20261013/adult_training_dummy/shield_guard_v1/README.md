沿用1536²共享画布、逻辑地面y1380、既有站姿主体约935px。新身体原图1254²统一最近邻1536/1254转换；没有逐帧bbox缩放或居中。S2头随屈膝前倾下移，不能把降低后的bbox高度当角色变小。头脸和衣褶仍有生成重绘漂移，未锁定原生精灵表。

剑复用attack_v2_geometry的canonical_wood_sword.png，SHA保持不变，握点(64,80)、刃基(64,140)、刃尖(64,460)，解析刃长320px。S0/S3复用原D0分层，另只替换画面左侧闭手局部；S1/S2从canonical做刚性旋转和平移，8px最近邻轮廓采样不代表改变剑长。

木圆盾只有一个来源。首次alpha>=16裁边后等比缩到416px最大径，放在432²图层、8px最近邻像素簇采样；此后全阶段scale=1，仅旋转平移。中心握持点固定(216,216)，位于盾脐背后，正面不可见，不捏造可见绑带。S0/S3低位，S1/S2抬高遮挡胸腹部分与靠盾侧下颌，视线仍露出。完整肩、肘、前臂、腕、拳保存在身体层，没有用截断肢体藏盾后。

图层从后到前：身体→剑→持剑手前景→盾。盾面alpha是单独保存的遮挡蒙版，持盾拳位于盾后，不能画在盾正面。关闭盾层可以核对完整手臂。握点和脚点是人工约±16px观察标记，并非引擎骨点。
