# 托曼与莫伦：主线剧情关键姿态

每人两张新全身姿态，首末复用已选锚，共四阶段；0 新人物。每人目录含深浅双底板、透明逐帧、单次GIF、完整raw和prompt、处理脚本及作者/独立审查。FINAL_STATUS记录审后状态，manifest保留作者阶段原样。source_evidence保留原字节锚、完整brief与人物卡/台本来源。

托曼：扶杖俯察车辙→抬头核前路。闭路线包，不迈步、不证明到场或路约已签；木杖上端/握点略升，刚性几何未锁定。

概念设定与关键姿态通过不等于连续动画、运行资源、任务状态或游戏验收。
