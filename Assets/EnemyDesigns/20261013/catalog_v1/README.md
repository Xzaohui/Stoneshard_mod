# 原创敌人设定集

浏览版范围：12 张静态选稿与每敌人两个独立关键姿势，共14页。首尾为静态总览和使用限制。

最终选稿已锁定：12 张静态图、24 个独立关键姿势均引用已发送版本。旧排版预览不属于交付。

## 源包范围

本目录的 PDF 排版源包仅含排版脚本、选稿引用清单、字体子集与字体许可，不重复封装角色 raw、提示词、旧候选或完整角色资源。各角色完整 raw 与生产历史已在对应角色交付包分别提供。选稿引用以项目根目录相对路径和 SHA-256 唯一定位；009、012 静态使用 idle_style_v2，005 短爪采用已交付 v2 选稿。

PDF 只对透明非空边界做版面裁边、等比 nearest-neighbor 缩放。源 PNG 保持只读、不重绘、不覆盖，不进行非等比拉伸。浏览版的显示大小不是游戏尺寸。

## 复现

使用 Python 3，安装 PyMuPDF、Pillow、fonttools；准备项目内 selected_sources.json 所列透明选稿。

命令：python build_catalog.py --font catalog_font_subset.otf --final

完整新字体可用 NotoSansCJK-Regular.ttc；脚本选择其中简体中文字体并保留 CID 字形编号后子集化，中文以嵌入字体显示。最终制作须完成选稿锁定并使清单状态为 approved_selected_sources_locked。脚本自动验证所有 PNG 哈希；rendered/ 仅为逐页视觉检查中间件，不随源包交付。

本册属于 Mod 原创提案，不是原作剧情事实。关键姿势不是连续动画；游戏网格、帧间对位、碰撞、装备组合、运行效果均未验证。未修改游戏文件或进行新的 Git 推送。
