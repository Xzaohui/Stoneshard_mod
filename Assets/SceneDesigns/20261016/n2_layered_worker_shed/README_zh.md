## 七个独立图层

全部 **1536×1024 RGBA PNG**；左上角(0,0)重合即是本次设计位置，alpha仅0/255。

1. `layers/00_ground.png`：完整夯土地面、浅木门槛、门外弧形撒灰。没有建筑或道具。
2. `layers/01_body.png`：完整无顶棚体、背墙、侧墙、柱梁、石脚与前侧低围板。中央入口宽敞，内侧不靠屋顶补洞。
3. `layers/02_roof.png`：独立粗木板单坡棚顶，整层可隐藏；没有建筑柱墙或地面。
4. `layers/03_living.png`：两床旧草铺、木箱上的水壶和碗、小凳，作为一个生活铺具层。
5. `layers/04_empty_coffin.png`：空棺与完整内底板，里面没有外套、尸体或其他物件。
6. `layers/05_loose_lid.png`：未钉合棺盖，靠在侧后墙前，单独可移除。
7. `layers/06_old_coat.png`：摊平旧外套，仅棺内中段有衣物，周边木板仍可见。

绘制顺序：地面 → 棚体 → 生活铺具 → 松放棺盖 → 空棺 → 外套 → 屋顶。
揭顶只隐藏屋顶；S04取衣后的视觉状态再隐藏外套。三个预览保持其余层位置完全不变，不重新生成场景冒充叠层。

## 设计与目视检查

- 从既有粗木雇工棚材质延伸为开前面的简棚，减少前墙和中柱对家属生活与空棺的遮挡。单坡棚顶属于本次美术设计候选，未替换原素材。
- 门外灰带只是民间顾虑的痕迹；无符文、亡灵、尸体、正式墓碑或死亡结论。
- 家属生活用品与空棺并存，空棺内只有独立旧外套。棺盖靠墙，未钉死。
- 盖顶时左右前柱与檐口实际遮盖衔接，无透明断带；揭顶后背墙、侧墙及地面连续完整。
- 生活区、棺内外套及松放棺盖在揭顶状态可见。道具未覆盖前侧门柱；外套不跨过棺缘，取走后裸露的底板是原有完整空棺层。
- 细节图是实际叠合像素的裁切放大，不是新画的假示意。
- N2外院拓扑只作只读参考：雇工棚门位[10,14]、返回点[10,16]、原生活铺具节点仍留在来源快照中。本候选不定义碰撞、可行走格、交互或新锚点，不声称遵循26px生产网格。
