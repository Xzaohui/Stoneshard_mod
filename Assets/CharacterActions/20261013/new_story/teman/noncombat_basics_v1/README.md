# 忒曼（FX-HNY）基础动作

2张独立全身日常静态动作，均为内置imagegen首稿；0修订。

- 左掌轻理右侧皮袖：左前臂跨身，左掌广面贴本人右侧皮袖，右臂低伸、右手松垂；两手分离，原帽网保持放下，双皮袖补缝绑结及双靴完整。
- 右掌轻扶原帽冠：右肘抬到头旁，右掌贴原帽冠左上外表面，左手低垂；没有掀网摘帽，网后五官可读，帽网补丁、皮袖与双靴保持。

保持已审母图本人比例、衣装和原物件侧别。仅alpha≤8及隐藏RGB清理；无人体编辑、拉伸、量化或插帧。
完整工具返回包含image_url payload。raw与返回payload逐字节核对。
source_hashes与sources保留母图、人物卡、对白、计划与来源SHA。联合交付planning_sources保留本组相关规划文本；角色sources/files按source_hashes保留相关源全文与图像。
仅可逆美术概念；不代表连续动画、原生精灵、装备兼容、碰撞或游戏运行。
