# G1 空手屈膝地坐静态概念

仅一张新绘姿态，唯一生成输入为 I0 站姿。I0、R2 坐凳、K1 单膝、R1 侧卧均为复用对照，不计新图。人物人数不变、GIF 为零。本目录未上传，未修改人物名单或游戏资源包。

交付候选：frames/G1_ground_seated.png；ground_seated_review_light_zh.png。深底板用于边缘复核，证据包保存 raw、prompt、来源快照、SHA、生成与处理日志、构建脚本和审查。

只做透明噪点清理与等比 nearest 排版；未程序绘身体、未分肢或非等比缩放。两条腿靴完整度按地坐规则审核；没有引用侧卧大幅遮挡特例。

manifest.json 冻结终审输入，终审之后不修改其涵盖文件。QA-independent.json 和 FINAL_STATUS.json 是后续独审与交付状态记录，不倒改冻结清单。

只称屈膝地坐静态概念，不代表坐下/起身动作、连续动画、原版必需帧、骨长、换装或运行验收。此项通过后本轮常见静态支撑研究停止扩列；步行/呼吸连续性失败不因本静态完成而消失。
