# 瑟拉 · 转面概念 v1

- 身份：BRY-NPC-SELA，布林独立夜渡船的租船人；不与 NPC-SENA 混同。
- 已批准的G四分之三图只读复用。批准仅代表人物美感与脸部，不代表换装、动画或运行验收。
- 新增：左侧面、背面各一张，builtin image_gen 独立顺序绘制；没有新增人物计数。
- 大像素簇、脸发、配色与瑟拉自身比例沿用G，不套米娅比例。
- 背面短肩巾、束发后形、素色背衣与腰部延续都是本次最简设计推定。金褐环状物依原图轮廓保留，功能未知，不新增武器、包或承诺。

## 文件

- `raw/`：两张生成原稿，保留全部原始字节。
- `prompts/`：两次生成完整提示词。
- `sela_side.png`、`sela_back.png`：原稿精确副本，不重画。
- `sela_turnaround_review_zh.png`：中文三视图审阅板。
- `sourcehash.json`：批准基准与角色卡来源哈希。
- `manifest.json`：画布、透明统计、处理、交付哈希和限制。
- `build_review.py`：仅裁透明边界并按相同0.60最近邻等比缩放、平移和文字排版。没有分别调整比例，没有身体绘制，没有新增GIF。
