## 使用边界与后续整理

本批是像素风设计审阅图，不是已导入游戏的最终精灵。人物与道具的纹理密度偏高；实际输出未达到提议的64×64逻辑单元、严格16色或整数倍率网格。透明PNG已确认含有效alpha，但半透明边缘与色数未按引擎标准验收。

四关键帧用于描述动态意图，不等于无抖动循环动画。船体、系绳与背景存在生成差异，需在引擎用图前统一裁切框、水线/脚底锚点、像素密度、调色板，并逐帧清理。建议轻摇循环起点6–8fps，最终节奏须实际预览后调整。

场景是空间与气氛参考，尚不是可走格、碰撞地图或可平铺瓦片。未修改剧情、游戏代码或提交远端。原始生成输出另有保留。
