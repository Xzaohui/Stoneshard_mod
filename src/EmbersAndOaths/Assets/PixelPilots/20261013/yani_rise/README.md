# 雅尼起身：共享锚点与低分辨率制作研究

2026-10-13。三个关键姿态，非骨骼动画、非原生风格验收、非游戏可用精灵。只新增本目录，原batch01/batch66、全局索引、runtime、资源嵌入与剧情状态均未修改。

## 结果先读

- 固定64×64透明画布；实际人物可见高度依次26、30、34px。34px仅参考预算，不是引擎标准。三帧用同一34/828缩尺，保留真实坐下到直立高度差，没有逐帧bbox归一化。
- 靠场景凳前柱配准x、统一源地面y902，保留人物前倾/伸腿/手离膝等原概念差异；每帧近侧靴底都在y53，地面排他边界为y54。两靴自然有透视高低差，不强迫同一行。
- 同一24色语义板，实际每帧20–21色。RGB采样先映射同一板，再按覆盖率40%与区域主导色降采样。无抖动、无误差扩散、无软alpha。
- 姿势可以读成坐姿→抬身→站直，腿间和凳腿内孔仍有负空间。不是机械平移：相邻人物alpha即使搜索最佳平移也仅约0.693、0.747 IoU。此测试只排除完全重复的平移剪影，不能证明运动学正确。
- **仍需结构重绘。** 原图是高密度插画式概念；降到该预算后分指、脸部表情、灰发纹理、衣褶和凳木纹均不可保真。已做有限像素修整并非精确自动提取。坐姿裤腿/手轮廓仅达到低分辨率动作读图讨论，非成熟人物定稿。

## 为什么不能只做对齐

原batch66的凳前柱、被遮凳腿和人物比例都有漂移。配准不能修复头部角度/大小、衣褶和四肢比例差异。这里把原三帧人物用人工追踪多边形与中性背景阈值分离，并在目标网格重新画**一张共享凳层**，再把三种姿态遮挡叠上去。凳层被遮挡的部分是设计重建，不能声称从原图准确恢复。完整凳永远同位同尺寸；最终图因人物遮挡不同而可见部分不同。

源图三帧本身站位近侧靴略有差异：本研究只固定低分辨率地面行，没有把全身任意拉扯成同一骨架。自动缩放、插值中间帧或光流不会补足正确关节机制，因此未制作假中间帧。

## 设计性修改与审查

1. 三个人物源多边形，去除原来会变形的凳与灰背景，保存`source_polygon_*.png`和透明源裁切。边界是人工判断，既有姿态未旋转或非均匀拉伸。
2. 目标网格凳重绘为一张有前柱、后柱、凳面和内孔的24色板子集图；用于三帧。不是新剧情道具，延续原短木凳。
3. 明确目标像素编辑：一像素眼点、灰胡茬符号、肩扣、浅袖口、手压自腿的合并手形。用区域规则把错误归到皮革/发色的橄榄衣服颜色简化回衣色。不添加支具、伤情、武器或助手。
4. 修整前的`character_XX_baseline.png`逐帧保留；全部目标格before/after和理由见`pixel_edits.json`。源mask和凳整层重画另注明，不隐藏在少量像素编辑数里。
5. 实际查看原batch01、batch66、最终native sheet和16x关键区。近侧/远侧手只剩块状表达；中帧重心和动作适配仍需动画专业审阅。未证明脚不滑、肌肉机制、起身平衡或流畅循环。GIF循环最后重置到坐姿是预览回放，不是坐下动作。

## 锚点定义

- `scene_anchor=[24,54]`是**画布场景参照点**，x靠固定凳前柱，y是最近靴底下缘。
- source-to-canvas: `x=19+(source_x-panel_offset)*34/828`；`y=54+(source_y-902)*34/828`。
- 三帧source panel_offset=`[0,500,1013]`，来源于源凳配准而非每帧人物bbox。第三图显示面板起点约1028，使用1013是主动把漂移凳前柱左对齐15源像素；不假装源图原本精准。
- 地面点不等于GameMaker origin；origin、collision保持null。无runtime验证。
