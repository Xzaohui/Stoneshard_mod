# 原作系统衔接约束

本页将社区资料转为本 Mod 的设计约束，来源编号见 [[来源登记]]；所有接口、保存方式和执行效果仍待干净基线验证。

## 地方委托与原作局势

**网页转述，S18：**[聚落局势](https://www.stoneshardwiki.com/zh/situations/) 中，集市按游戏日持续；部分负面局势与失败契据及相关副本关联，运输问题还可能形成连锁影响，不能统一视为固定时长的倒计时。

**原创规则：**日常只调整新增站点 supply/safety/maintenance。原作局势作为候选需求背景，在未知接口下不写入其状态。送粮可恢复新客店的普通库存，不能解除原作副本关联危机。未来若需要联合治理，要分别满足原作解决条件和新增委托条件，且只由原作机制结算原作事件。节庆可提供新的临时委托，不延长或重置原作活动。

原作“瘟病”局势、背景中的历史瘟疫和 R05 原创实验引发的局部热病分别记账；[[支线_SQ07_药不是赎罪券]] 不宣称一次治疗治好全世界。DT02 恢复新增水井服务，也不自动删除原作负面局势。见 [[日常委托规则]]、[[晶石机制与叙事规则]]。

## 故事副本与随机条件

**网页转述，S19：**[副本条件](https://www.stoneshardwiki.com/zh/mechanics/dungeon-conditions/) 区分副本类别、契据目标和附加条件；“机关入口”可能封锁出口，“疯狂低语”会制造误导声音，部分条件涉及仪式或怪物再生。

**原创规则：**首次故事布局不得无审查继承随机封门条件；若保留封门，必须有可见且不依赖技能检定、消耗品或随机钥匙的机械解除方法，不能以击杀 boss 为唯一退路。若未来不能隔离该条件，则采用独立故事场景作为候选，不宣称已验证可行。

声音只能提示风险，不能直接认证 E01–E05 或当作死者可信证言。遭遇复活和召唤机制时只作用于允许刷新的普通敌人；关键人物死亡、已收证据和已操作机关不随再生回滚。首次初始化与存档恢复分开审查。推荐角色等级不是副本原生 tier，后续另做校准。见 [[副本索引]]、[[证据与结局]]。

## 商人补货、修理与奖励

**网页转述，S20：**[商人库存与修理](https://www.stoneshardwiki.com/zh/mechanics/merchant-stock-and-repairs/) 分别描述城镇和个体商人的补货条件，存在不同周期与任务、声望、升级条件；唯一物品与修理材料也有独立规则。

**原创规则：**公告板 24 小时刷新仅更新公告，不能刷新所有商人、固定贩售稀有品或补满修理资源。新药品到货只影响被明确列出的原创服务渠道；旧库存仍按原作结算。不能通过买卖、重进场景或重领抄本复制唯一物品。经济校准加入买药、装备损耗、修理材料与旅费；Wiki 提供的公式候选不能替代实际价格测量。见 [[经济与奖励]]。

## 犯罪与证据财产

**网页转述，S21：**[犯罪与惩罚](https://www.stoneshardwiki.com/zh/mechanics/crime-and-punishment/) 描述按势力处理的犯罪记录，以及罚款、监禁和赃物没收后果。

**网页转述，S23：**[赃物](https://www.stoneshardwiki.com/zh/mechanics/stolen-goods/) 汇总的商人配置拒收赃物，并保留部分具体处理路径的不确定性。人物职业名称不能单独证明其拥有完整销赃服务。

**原创规则：**[[势力_黑账中间人]] 的私下交易不自动成为原作通用销赃接口。合法抄录只复制已登记的线索内容，不删除原物的赃物标记；提交信息与交出实体财产分成两种目标。证据原物被没收时，只恢复允许保留的调查信息，不凭空补出可售原物。地方信任、阵营承诺和结局责任不能冲销原作犯罪。见 [[任务状态与依赖]]、[[证据与结局]]。

## 住宿、休息与保存

**网页转述，S22：**[休息与保存](https://www.stoneshardwiki.com/zh/mechanics/rest-and-save/) 区分床位、零小时歇息与其他保存方式；租赁、通缉、敌人或危险状态可能阻止睡眠。营火本身不是保存点。

**原创规则：**区域最低服务保障表示有可到达的设施与返回通路，不保证任何犯罪、战斗或身体状态下都可睡眠。地图分别标注取暖营火、合法床位、医疗服务和待验证保存能力。中立仅指不要求本 Mod 势力信任，不免除原作犯罪条件。禁止新增任务封锁所有回程；玩家仍需按原作解决敌人、租住及危险状态。后续不得依赖 Manual Save 弥补本稿的回程设计。见 [[世界状态与商队]]。

## 未来接口验收情形

| 情形 | 必须满足的设计结果 |
| --- | --- |
| 原作调查完成前后进入营地 | 仅完成后开放 MQ01；不再次发原作饲料 |
| 原作聚落危机期间完成送粮 | 新站点恢复，原作危机按其机制保留 |
| 24 小时公告刷新但商人尚未到周期 | 只改公告，不强制补货 |
| 首轮故事副本出现封门候选 | 条件排除，或可无技能代价开启撤退路线 |
| 读档、仪式再生、重访副本 | 唯一人物、证据、机关和奖励不重置 |
| 有通缉或未付款来到新增客店 | 提示真实受限原因，不以中立身份强制清罪或保存 |
| 赃物证据遭没收 | 已登记事实可继续调查，财产后果保留 |

上述是未来应测试的要求，当前仅文档逻辑检查。关联 [[实施阶段与验证门槛]]、[[创作边界与待核验]]、[[系统逻辑索引]]、[[中文Wiki参考与设计映射]]。
