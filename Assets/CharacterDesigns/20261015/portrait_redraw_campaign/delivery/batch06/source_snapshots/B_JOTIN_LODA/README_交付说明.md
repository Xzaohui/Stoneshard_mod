## 核验与复现

- python3 verify_source_package.py <源包.zip>：全ZIP CRC、逐文件SHA-256、目录成员完整性核验。
- 安装Pillow后，在解压目录执行 python3 reproduce_candidates.py --output <新的空目录>：检查raw与完整工具返回字节，按原算法复现包内全部候选，并比较RGBA像素和PNG字节。只写新目录，不改冻结文件。
- 本次Pillow为12.3.0；不同版本可能影响PNG字节。全部13份候选离线复现通过；四张选稿的生产目录、独立QA和交付副本SHA一致。
- 两个源包均实际解压再次复现；每包报告为 portable_reproduction_verification.json。封包前后全部生产目录和独立QA哈希一致。
- 生图本身不承诺确定性复现；此处逐字节复现仅指已存raw至派生候选的机械流程。
