## 五官结论

- 蔻芙/雅铎/娜娅等近正面大黑眼、亮眼区、小微笑嘴与圆颏趋同；清楚不等于符合原版风格。角色卡明确的成年身份不受可爱脸观感改变。
- 伊莲/罗温的眉弓、侧鼻、短口线比较能表达朝向和克制神态，但依靠大量细碎阴影，直接缩小会丢失；应保留表情方向而非照搬每条线。
- 近1:1之外，还要核眉眼暗簇、鼻侧明暗、口线、皮肤颏。放大眼白、增肤色或拉长下巴不等于美化。胡尖、辫尾和发髻不替代实际头部边界。
- 历史瑟拉v1、妮尔v2、罗温v1、矿工组v1只作对照；不能用这些版本否定最新候选，也不新增重复重绘任务。
