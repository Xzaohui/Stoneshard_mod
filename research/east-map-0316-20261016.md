# 0.3.16 东扩地图底图与路网（2026-10-16）

续接 [0.3.15 实测](east-surface-0315-20261016.md) 的纸图硬色块和道路断段。沿用同一稀疏代码工作树；只处理已开放的两格及绘制尺寸，不把本批当作完整八列扩张或最终灰堤岸线完成。

## 本地接口证据与原因

对部署的 0.3.15 资源包只读核对，未保存原作完整代码或图集：

- `r_GlobalMap` 房间格 `(118,59)`（本地 `(41,37)`）的 `Biomes=2`、`Sea=0`、`Steppe=0`、`LocalBorders=24`。相邻 `(117,59)` 的 `Steppe=15`、`LocalBorders=0`。因此任务格是缺少草原叠层且残留旧纸边框；先前“可能保留海层”的假设被本轮格值排除。
- `scr_globalmapBatchInit/Resize` 维护 16 个正常/纸图批绘制网格，原生裁剪后宽 42。0.3.15 的生成后扩展仅把 terrainGrid 改到 50，未同步这些绘制网格。
- `o_globalmapPartRender User 11`（CODE `Other_21`）使用批绘制网格生成缓存，不能只改地块的 `Biome/room_type`。`scr_glmap_addSprite` 同时写正常与对应 `_paper` 精灵列表。
- `scr_glmap_getRawIndex/findRoadTile` 按邻格及 Road 的北/西连接位选择道路末端、直线、弯道/交叉。原生 `DrawRoad` 用该结果及 `s_groad_steppe/s_groad`，不能在地图上单画一条与地表数据无关的线。
- `scr_normalizeImageIndex` 仅做帧数归一化，无随机调用；新绘制仍不改变世界种子序列。

以上为本地 0.9.4.25 / MSL 0.13.2.0 的接口事实，不证明所有地图、存档或危险度行为。

## 实现

在已有 42→50 的一次性扩展块中、原生缓存/迷雾/纸图初始化之前：

1. 同步 16 个绘制网格宽度，保留原有矩阵，只把新增列初始化为原生空值 `-4`；封闭新列使用原生正常/纸图完整海面帧，与其 Sea 地块数据一致。
2. 清理已开放两格的旧草原/海/水/道路/纸图边框绘制项，补完整原生草原叠层。
3. 两格使用同一条道路数据，撤掉通向未开放北/南格的旧连接。仅在原西邻格实际有路时接入西侧；用原生邻格算法重画两格及必要的原西邻格道路，正常/纸图同步。
4. F6 增加只读 Road 数据、原生道路帧和地图绘制宽度诊断；不传送、不改人物、不调用保存写手。

原地图编辑器格值、元数据、图层、实例及顺序保持；新增独立输入/读回指纹校验绑定候选和实际组合输入，补上既有工具对 `r_GlobalMap` 宽度例外过宽的问题。所有检查仍只属于离线证据。
