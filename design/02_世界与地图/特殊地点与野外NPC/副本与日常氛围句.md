# 副本与日常氛围句

## 边界

- 全部为Mod原创；副本句不揭未核真相、不指认凶手；日常句不替当事人表态。
- 不含奖励、不推进任务、不写状态键；播放条件只读时段与 `resolve_*`。
- 未做：触发距离、作息与配音（见[[特殊地点阶段制作与校准规程]]）。
