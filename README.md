## 当前测试入口

重启游戏，回到商队所在的世界格，鼠标点击「绳匠玛拉」。前置为原版《葛文涅尔的答复》完成、商队可用。接受委托后，附近出现标有「旧渡口堤道」的入口。不需要旧迟信、抄本或海关入口。

新开篇从失踪守夜人开始，包含现场矛盾、人物解释、两条可执行路线和不同回访；计划执行前可改，执行后冻结。沿用原生NPC对白、门、接近、保存与转场。

<details>
<summary>验收路线（含剧情剧透）</summary>

1. 找玛拉接取，到旧渡口，可先问追索人托雷。
2. 查看东侧「断绳的钟架」，进入钟房查看「角落的铺盖」，分别选择查看。两处都须实际观察。
3. 找伊沃，追问钟声会带来什么；选择暗渠或公开交涉。
4. 暗渠路线：走钟房东侧通道，到蕾雅处明确确认撤离。公开路线：回桥头找托雷，明确确认家属债票作废、伊沃留置。
5. 未执行时可回伊沃处改计划；执行后不能改。对应角色离场或留置，托雷反应不同。
6. 从断桥西侧「返回商队」回实际出发点，告知玛拉；可追问她起初的隐瞒，两结案对白不同。
7. 分别验收退出保存、睡眠、重载和重访，确认状态/选择不回退、不重复结算。

</details>

## 场景与美术

新增三间1040×780场景：断桥两岸与窄堤、钟房及侧通道、折返暗渠。地面和原生碰撞由同一26像素格定义，不使用海关整张背景/前景；复用原生命周期控制器与少量原素材。

原创透明钟架由imagegen生成，保存在 [night-bell-v1.png](src/EmbersAndOaths/Assets/night-bell-v1.png)，内嵌进DLL/.sml/data，不依赖外部图片路径。目前地面与墙边仍是布局美术，人物借用原生精灵；一件钟架不代表场景全部完成最终重绘。

[实际布局预览](artifacts/night-layout.html)展示候选包碰撞和交互坐标，不模拟真实光照、点击与寻路。
