## 1. 唯一交付形态
| 形态 | 尺寸 | 用途 | 约束 |
|---|---|---|---|
| 对白头像 | 74×100 | 对话面板 | 正面近景，脸约占高度 70%，深色底，RGBA，二值透明 |
| 地图精灵 | 35×44 | 场景站立 / 行走基帧 | ≈2.5 头身，人物高约 34px，原点按现有 Hd2dArt 约定 |
| 行走帧 | 35×44 × N | 四向行走 | 帧数与朝向以原生导出为准（阶段 1 依赖本机导出） |

设定图、概念卡只作中间稿，最终入库只能是上表形态，不得另起画风。

## 2. 像素纪律
- 整数像素网格；禁止抗锯齿、半透明、软边模糊。
- 透明像素 RGB 归零；alpha 仅 0 或 255。
- 色数：精灵 ≤ 26（目标 17–22），头像 ≤ 40（目标 16–22，对标原生 16–18）。
- 外轮廓：1px 近黑（约 #1A1412–#2A221E），精灵近黑描边占比目标 84–90%。
- AI 流程：image_gen 只出大块像素原图 → 众数下采样到目标尺寸 → Lab 量化 → 人工逐像素修。禁止高清插画直接缩小。

## 3. 脸与肤色
- 画法对标原生：粉红肤色 + 紫褐暗部，3–5 阶大块明暗，不画细眼线和高光大眼。
- 原生肤色色阶参考：`#FDC499` `#F57C73` `#9E5E61` `#8B3B4A` `#73362D`。
- 眼睛：2–3 像素暗块即可；允许皱纹、胡茬、不对称。

## 4. 色彩与识别
- 低饱和土色为底；每人保留 **1 个识别强调色**，主角强调色不得与路人重复。
- 当前约定（可改）：玛拉 = 红围巾；伊沃 = 灰平帽。
- 剪影：每个主要角色至少 1 个独特轮廓要素（帽 / 斗篷 / 发型 / 道具），全身黑剪影须能互相区分。

## 5. 玛拉头像方向（待拍板）

|---|---|---|
| v3 | 平面色块更开，颧骨暗面与红围巾对比强 | 人物识别更清晰，接近审查方向 |

- 与原生同板、同倍率对比；不得只看放大稿。
