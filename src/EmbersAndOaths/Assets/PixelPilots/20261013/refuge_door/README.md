# 避难门 door63：刚体铰链四姿态像素修正提案

## 范围与结果

本目录是新绘制的 128×128 小尺寸像素几何提案，不是原版精灵提取，也不是把 v4 直接缩成成品。沿 batch58 v4 的上视、左铰链、右 keeper、上方向内开几何，参考石灰墙、木、铁、黄铜配色，明确重建固定墙/门框、固定铰链座、唯一局部门扇及随扇锁舌。原图、剧情、游戏包与运行资产引用未改。

四个姿态为 0°、30°、60°、90°。全部已解锁、锁舌已回缩；这四帧只隔离检验门扇转动，**不是原稿“锁住→缩舌→半开→全开”的完整动作替代**。若以后制作完整解锁动作，应另补锁舌伸入 keeper、回缩的局部状态，仍不能用开门代替人员实际撤离。

## 几何与采样

屏幕 y 向下；室内在墙上方。固定轴 P=(32,92)，局部轴=(0,4)，局部端点=(64,4)，两锚点间门长恒为 64px。局部图宽为 65 像素中心、厚度 9 像素；不将图宽 65 与锚点长度 64 混称。

前向矩阵为 `[[cosθ,sinθ],[-sinθ,cosθ]]`，绕 P 旋转。门扇和回缩锁舌使用完全相同的逆映射、最近邻取样；每帧不再绘制一扇新门。局部坐标最近邻取整为 floor(v+0.5)。17 色共享调色板，实际不透明复合帧用到 16 色；透明层仅 alpha=0/255，无抗锯齿、无抖动。固定铰链的壁座延至左墙，避免“轴在空中”。右墙 keeper 固定在 (99,92)，闭合未锁帧有清晰脱开间隙。

## 已查与未查

已查：四帧矩阵正交、轴不移、几何锚点长度恒定、锁舌与门扇同变换、固定层不改、四采样姿态门扇与墙/keeper 无不透明像素交叠、二值 alpha、调色板、GIF RGB 与 PNG 完全一致。完整生成两次，27 个生成/脚本文件字节完全一致；逐帧实际打开查看，转动朝同一上侧，90° 门扇没有漂长，黄铜件留在自由端。

最近邻斜转会改变阶梯边、轮廓像素数量与离散包围盒；“刚体门长不变”指几何锚点，而不是声称每一栅格轮廓的像素计数不变。四姿态数据不等于连续扫掠体、接触、深度、受力、真实门锁、公差、碰撞网格或引擎运行验证。简化墙块材质与微型黄铜锁还需美术定稿。
