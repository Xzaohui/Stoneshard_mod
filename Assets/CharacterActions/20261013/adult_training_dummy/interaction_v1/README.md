# 无武器近地交互 v1

原创动作关键姿态研究，不是原版动作复刻、完整补间动画或引擎资产。已有官方参考没有证实该类近地交互的具体关节动作。本轮没有追加未确认的原版检索，也不赋予具名人物新技能或剧情。

## 内容

- 3张内置imagegen新身体图：I0无武器站立，I1屈膝俯身，I2近地伸手。
- I3回稳直接复用I0，不计新图。GIF顺序I0→I1→I2→I1→I0；倒用I1仅提供起身过渡，不冒称新绘起身帧。
- 从首帧到末帧双手均空置，无武器、拾取物、任务完成提示。
- 脸、灰色兜帽、蓝灰绗缝衣、棕腰带手套裤靴保持；右向三分之四视角，不全图镜像。

## 文件与像素处理

raw保存三个1254²原始工具输出（工具未实际输出请求的1536²）；prompts保存原提示词。生产帧置入1536²透明共享画布，所有帧采用共同倍率935/761=1.228646518，以最近邻统一缩放；无逐帧bbox缩放。统一倍率后仅平移对齐画面右靴下边至逻辑地面1380；平移值见manifest。原稿含低alpha杂点，生产帧以alpha≥128做二值透明并清零透明RGB，保留原稿与哈希。

layers保留完整身体平面层和空FX层，可精确重组；没有伪称恢复原生骨骼、手臂或衣服下隐藏结构。当前无道具，不为分层而制造空的武器。脚底与膝部接触、衣摆遮挡通过近景图检查。右靴最下轮廓锚定，另一只靴与鞋口仍有生成细节漂移；不能据此声称无滑脚的连续动画。

## 验收范围

每张独立PNG透明画布1536²。GIF单次播放，不含循环扩展，预览节奏3200ms仅供讨论。检视页包含四阶段与两张脚/膝/手近景；I2指尖距离逻辑地面约35px（手动估点），表现伸手接近地面而非触地抓物。

头部因俯视姿态旋转，非新增身份；成人成熟度仍沿用已有训练概念。原始图→平移图应审脸与身形一致性、脚支撑、膝屈曲与近地手位置。engine_origin、碰撞、纹理裁剪、原生FPS和方向数均unknown/null。

独审通过前不上传。脚本可复现预览、帧和manifest；不会编辑其他任务目录或runtime。

## 跨动作尺度修订

原已审1.0研究版保存在study_scale_1_0，不覆盖原稿。防御G0与攻击D0的无剑身体层alpha≥128可见主体高935px；本次I0原稿高761px。整组固定倍率935/761，统一最近邻缩放后每帧仅平移对齐脚底。头部兜帽顶至颈底人工估高：G0约333px，本组原稿约267px，统一后约328px（约1.5%差异，属于概念轮廓差异，非逐帧拉伸）。同一身体尺度不等于全部装备与原生骨骼通过。跨组比对图见cross_action_scale_review.png。

## 独立复审结果

统一尺度版已通过独立概念关键姿态复审，详见主QA-independent.json。G0/I0实际主体高均935px，所有帧同倍率重建及图层合成逐像素一致。I2最低可见手指距逻辑地28px，人工估点约35px，均为近地未触地。脸部与衣服细纹理仍有轻微生成差异；这是可讨论关键姿态，不是无漂移补间或装备运行验收。主图与manifest已冻结。
