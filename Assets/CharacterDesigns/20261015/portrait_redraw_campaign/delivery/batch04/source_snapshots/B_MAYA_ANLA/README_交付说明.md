## 核验与复现

- python3 verify_source_package.py <源包.zip>：全 ZIP CRC、逐文件 SHA-256、目录成员完整性核验。
- 安装 Pillow 后，在解压目录执行 python3 reproduce_candidates.py --output <新的空目录路径>：检查 raw 与完整工具返回字节，以原整幅最近邻/量化算法复现该包全部候选，比较 RGBA 像素和 PNG 字节。只写新的输出目录，不改冻结文件。
- 本次使用 Pillow 12.3.0；不同版本可能影响导出字节，报告保留版本号。10 张候选全部便携复现通过；4 张选稿的生产来源、独立 QA 与交付副本 SHA 一致。
- 源包已实际解压并再次复现全部候选；逐项报告见各包 portable_reproduction_verification.json。所有原生产目录与独立 QA 在封包前后哈希一致。
- 工具返回包含完整生成图 data URL，供离线复核，无需服务账号、密钥或再次生成。
