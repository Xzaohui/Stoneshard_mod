# 台本_FX_野外人物对白

本页是[[特殊地点与野外NPC对白扩展计划]]的当前产出：36 名Mod原创野外人物，覆盖[[特殊地点与野外NPC清点]]登记的地点类型。对白为Mod原创（S94/S97/S99 中文先行，S106 补英文稿；英文同样标 Mod 原创，不冒充原版译文）；不新增奖励、不设全巡前置、不占原生服务；每人的知情范围与拒绝出口见各卡。每人另有条件回访：任务进行中/完成后、先做或后做关联任务，以及本人缺席时旁人可代述的有限句。

> [!info] 播放规则
> 只有本人存活、在场且愿谈时才播新句；死亡或缺席只保留事前有限陈述，不能由旁人代播。同一事实在不同人物口中有不同版本，但不含本人无权知道的内容。

## 德茹·石场看守（`FX-QRY`）
