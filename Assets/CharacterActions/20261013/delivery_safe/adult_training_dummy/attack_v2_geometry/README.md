## 真实修正

以D0木剑外貌为参考，用已获授权的像素编辑脚本重建一张全长剑层（不是从原画恢复完整遮挡结构）。固定局部握点(64,80)、刃基(64,140)、尖(64,460)，刃轴长320px。四帧只作刚性旋转/平移，不逐帧拉伸；最终轮廓在8px网格最近邻采样，栅格边缘有网格内误差，不称渲染边缘精确同像素数。

每帧保存身体基底、独立变换剑、前景手套，以及清除旧剑/手套保护蒙版。局部去剑后清除孤立残片，原始生图不改。图层顺序为身体→剑→手掌前景；D1包含腕部保护。所有握点、旋转角、解析刃端点和SHA见manifest。重新合成与导出PNG逐像素相等，见recomposition_checks.json。
