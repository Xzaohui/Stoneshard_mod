# 动作补缺概念归档

每项只执行一首稿与一次明确硬错修订；逐字实际提示词先保存再执行，原工具返回与生成原图完整保留。只采用 builtin imagegen 绘制。所有旧母图与旧动作的原文件未修改，sources 中为相同 SHA 的只读来源快照。

最终选用状态只以 FINAL_STATUS.json 为准；失败候选不会改名冒充成品。两次原始图、透明候选、浅深合成、相邻阶段对照、作者检查、正式独审、工具参数与返回均保留。alpha0 下隐藏 RGB 不作为可见错误；仅清理 alpha<=8 背景及隐藏RGB，没有脚本画身体、量化、拉伸或修补轮廓。

所有图片是独立关键姿势概念，不是连续循环、已配准 sprite sheet、碰撞/装备合成、GIF 或游戏运行证明。共同 origin、相机/头部尺寸和武器尺度仍待后续制作核验。001 的旧戒备到短刺间矛长尤其未验证；使用短刺作为本轮武器主参考也不代表跨旧姿连续性已解决。

工具原返回以 tool_return_vN.original.json 为准，文件从工具实际返回对象序列化归档，从未覆盖；raw PNG 为工具输出文件的字节复制。准备脚本只处理透明背景与等比最近邻排版。
