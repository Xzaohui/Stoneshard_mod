# Mara native-style pilot specification

Status: first four-image pilot authorized by user via parent; two Mara assets assigned here.
Scope: one dialogue portrait and one neutral full-body map standing sprite, independently composed.
Portrait: 74 x 100 target pixels, at most 32 visible RGB colors, five or fewer skin ramps.
Map: 35 x 44 target pixels, at most 20 visible RGB colors, black/near-black boundary, binary alpha.
Style: broad hard-edged pixel clusters, v4 large locks, muted warm palette, mature worried direct gaze, no infantile face, no dither/speckle.
Identity: Mara, early/mid thirties, upright, ropeworker. Brown low-pinned hair, worn muted red scarf, ochre thick-cloth clothing, beige ropework apron, pale worn sleeves, simple boots. Unfinished rope loop and old small whistle may read as subordinate marks, never oversized costume additions.
Portrait focus: end long nasal shadow, define nose wing and restrained cheekbone planes without flat half-face mask or v3 scattered highlights.
Map focus: compact full body, 1x readable silhouette, short limbs, distinct hair/scarf/apron clusters, no added action.
Generation: built-in imagegen only. One initial plus at most one targeted revision per asset. Source PNGs measured, retained intact. No Python-drawn character geometry.
Derivation: transparent crop, nearest-neighbor target-size export, palette quantization without dithering, alpha threshold; all recorded. Derivative target image is not automatically a native-pixel pass. Visual 1x and integer enlarged review must decide.
Never change old assets, character cards, source code, another worker's directory. No commit, push, upload, or delivery in this task.
