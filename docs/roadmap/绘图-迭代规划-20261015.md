## 风险
1. **生图模型难以稳定画出原生像素精度**
   - 每张都要靠脚本量化再手工修，人物这部分自动化处理已经到头
2. **调色板预算会削弱阴影层次**
   - 这一点在第三、四批已经出现过
3. **codex 额度消耗**
   - 阶段 3 的量很大，需要控制节奏
4. **规格可能变**
   - 名册和版本口径（README 写 0.3.1，实际已部署 0.3.5）不统一，素材可能要返工
5. **多个 bot 同时改仓库容易冲突**
   - 需要明确目录归属
