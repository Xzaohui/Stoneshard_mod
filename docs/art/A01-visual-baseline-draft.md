# A01 视觉基准草案（布林码头小院）

日期：2026-10-15。状态：**DRAFT**，待用户确认能否作为全项目场景风格基准。
源图：[`assets/A01_visual_anchor.png`](assets/A01_visual_anchor.png)（1040×780，第一批概念定稿）。

## 1. 为什么选 A01
- 布林码头小院是 0.3.x 后半段要反复出现的城市外院尺度。
- 已有完整构图：水面、岸线、木构、石砌、杂物层次齐全，能同时约束室外地面、建筑立面和前景遮挡。
- 与 N1 / N2 已部署场景同属 26px 正交斜俯视角，可直接拆层入库。

## 2. 视觉要点（作为基准时必须遵守）
1. **视角**：方格正交斜俯（top-left 受光），禁止菱形等距、透视灭点。
2. **密度**：1px 原生像素；石块、木板、杂物的颗粒尺度须与 35×44 人物同屏不打架。
3. **调色板**：入库时量化到对应批次锁（N1 用 DEN-N1-128；N2 / 外院用 R01 / DEN-N2-128）。
4. **层次**：至少能拆成 backing / floor / structure / foreground；structure 不得侵入可走遮罩。
5. **材质**：泥土与碎石要有大尺度明暗起伏，禁止明显 26px 棋盘；水面用 1px 波纹，不用粗块拉伸。
6. **接地**：建筑与道具必须有不透明抖点接触阴影（可烘焙进 floor / backing，以通过 structure 区域规则）。

## 3. 拆层计划（定稿后执行，本草案不改资源）
| 层 | 内容 | 尺寸 | 备注 |
|---|---|---|---|
| backing | 远岸、水面、天空/远岸轮廓 | 1040×780 | 全幅不透明或水面二值透明按 N1 惯例 |
| floor | 可走地面、码头木板、近岸土 | 1040×780 | alpha 严格等于可走遮罩 |
| structure | 墙、柱、栏杆、固定建筑 | 1040×780 | 仅可走区外 |
| foreground | 近景遮挡、屋檐、挂物 | 1040×780 | 仅可走区外 |
| props（可选） | 桶、绳、招牌等独立精灵 | 按物件 | 单独注册 Hd2dArt |

步骤：人工标可走矩形 → 按矩形裁 floor → 墙与立面移入 structure → Lab 量化 → 跑 `Validate-Hd2dN1`（若挂到 N1）或对应批次校验 → 更新 manifest。

## 4. 与已有场景的关系
- N1 钟屋 / 暗渠 / 岸院：镜头与墙可见性问题见 `docs/roadmap/绘图-迭代规划-20261015.md` 阶段 2；A01 定稿后用于统一岸线与地面材质。
- N2 外院（sites）：地面密度与接地阴影以本基准的第 2.2 / 2.6 条验收。
- 采石场：石材色阶对齐 A01 的土灰比，避免独立“概念板”色。
