# 原作剧情与对话系统参照

本轮按用户“先扒一下目前紫色晶石的剧情与对话系统作为初始参照”的要求，对本地 `vanilla.win` 的字符串表做只读结构探针。结果只保存键名、分布、定位索引与不超过约46字的片段，不保存原作完整对白；探针工具为 `research/tools/Probe-OriginalKeyIndex.py`，记录为 `research/original-key-index.json`。这是静态表结构，不是游戏运行时行为验证。

## 物品与任务描述风格（S89）

2026-10-12按用户“细粒度设计、贴合原作风格”要求，对原作 STRG 中的物品与任务描述做只读采样（仅存短例与定位索引）：

| 类型 | 样例（≤46字，定位索引） | 观察 |
| --- | --- | --- |
| 物品名 | `Pickaxe`[23110]「从佛尔霍特的金矿到北疆的犯人石场，到处都能见到这种鹤嘴镐」 | 描述=来源地＋用途，一句话收束 |
| 物品名 | `Katzbalger`[23493]「这把剑造型入时，颇受城市联盟的雇佣兵青睐」 | 以行业/派系的使用者说话，不夸数值 |
| 物品名 | `Skonfert Sword`[23496]「斯孔弗特炼场广博，手艺精湛的铁匠众多，因此而闻名」 | 地区背景一笔带过，落回物本身 |
| 消耗品 | `salve`[31386]「这个膏剂本来是治疥疮的，治伤的强力功效纯粹是偶然发现」 | 允许一处冷幽默/意外发现 |
| 任务日志 | `fetchOrmond_desc`[32973]「奥斯布鲁克的裁缝霍特让我给他弄一张熊皮」 | `*_desc` 用第一人称“让我…”；点名人物与实务 |
| 任务日志 | `VogtSmithBribe_desc`[33013]「铁匠工场督工…一看到前锋司务长的信，就和和气气地说…」 | 以过程与口气叙述，不写数值奖励 |

**转写的写作规则**（Mod原创描述一律遵循）：1–2句为主、≤约60字；落在来源地/用途/行业惯例/谁在用；允许一处分寸感（冷幽默、偏见、意外发现）；不写抽象赞美；不暴露后台标识；不承诺无限供给与永久效果；英译保持同义克制。落地见[[原创物品与装备总表]]与[[人物细描与随身物]]。

## 原生任务、契据与信息渠道

- **任务**：`questManticore_*` 以阶段键展开（`_FindCave`、`_ExploreCave`、`_ElixirWait`、`_TakeCradle`、`_BringCradle02`）；`GuinnelAnswers_MoveToCamp(_desc)` 则配套任务标题/描述对。命名＝`quest<名>_<阶段>`，与 `questsDataMap`、`quest_stage_check` 等引擎键配套。
- **契据**：`contract_*` 274 条（`contract_faction`、`contract_complete_count`、`contract_raw_data`、`contractSeal1–5` 等），契据含派系归属、封印档与完成计数。
- **传闻**：`rumor_*` 160 条按地点成组（`rumor_cave6…cave1`、`rumor_mine2/1`、`rumor_abbey1`、`rumor_siegeCamp1` 等），说明传闻是“地点＋条目”的具名内容，而不是通用池。
- **局势**：`situation_name/effect/desc` 与 `situationsTextMap`、`situationsDataMap`；与 [[原作系统衔接约束]] 中聚落局势的转述一致。
- **书籍**：`treatise*` 423 条，说明读物是独立内容族。

## 对照使用边界

- 本页是结构参照，不复制原作台词；具体句子只在 `research/original-key-index.json` 以键名、索引与短片段留证。
- 字符串表只承载文本；对话树的分支/条件/跳转在GML代码与Dialogue对象层，本页未反编译核对。逐NPC分支细读仍按 [[特殊地点与野外NPC对白扩展计划]] 另行只读核对；本页不替代该阶段。
- 原作档位名称、阈值与运行时结算未在干净基线实测，探针只能证明字符串存在及分布。
- 声誉界面截图（S24，王廷/灰色军团各四地点）与本次字符串结构互相独立，均不作为可达性证明。
