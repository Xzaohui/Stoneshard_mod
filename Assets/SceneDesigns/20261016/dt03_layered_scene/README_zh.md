已查看完整真实叠合、分层图、墓标局部、核验桌与工牌落布局部、木挡/柜脚局部和独立工牌近景：

- 墓标、桌脚和木挡石脚均与现有地面接触，未见矩形透明边缘或接缝断带。
- 上左方受光、右下侧阴影方向一致；地面与物件都采用褐土/盐灰石/旧褐木，构图保留中下部通路和两侧站立空间。
- 前景位于画布边缘；未遮住空名标、工牌或记录柜。
- 透明输出生成时含柔边，使用alpha 50%阈值清除周围半透明晕边。保留原始PNG，未改画、不调色、不透视扭曲。
