## 完整性

`package_manifest.json` 逐项记录源包内容和主动排除项。`archive_verification.json` 记录 ZIP CRC 全检、解压后各项 SHA-256 对照及源目录冻结快照未变检查。`SHA256SUMS.txt` 记录四项交付文件的哈希。归档后校验记录在 delivery 目录，ZIP 内含归档前的包内容清单，避免自引用哈希。

`build_review.py` 只重建展示布局；`package_sources.py` 只制作归档与校验。制作人员原有派生与诊断脚本保留在各自源目录中，重跑它们可能更新该目录产物，因此交付验收应以清单记录的候选 SHA 为准。
