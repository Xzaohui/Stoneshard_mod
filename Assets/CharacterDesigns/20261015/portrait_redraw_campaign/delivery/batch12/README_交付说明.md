# 第十二批头像重绘交付

本批交付三张 74×100 透明底候选：埃墨·衬（EMO）v2 MAXCOVERAGE、奇恩（KIEN）v2、科纳（KONA）v2。三人均通过独立审查，状态为带备注候选。每人均实际生图 2 次，保留 v1/v2 完整原始图、完整提示词与工具返回、来源快照、生成记录和自审；独立 QA 单独存放。

## 交付与复现

- 总览同时展示 1× 与整数 4× 最近邻放大。三张单独 PNG 与各自冻结候选逐字节一致，未补画像素。
- A 包包含 EMO 与 KIEN 完整生产资料；B 包包含 KONA 完整生产资料及 HEL 文本冲突证据。两个文件都是可独立解压的普通 ZIP，不是分卷。
- 每包附逐项 SHA256、CRC32、完整文件清单、独立 QA、选图冻结证据、交付总览及三张交付 PNG。
- 在解压目录运行 `python3 reproduce_candidates.py --output <新的空目录路径>`，即可使用 Pillow 从该包 raw 原始图复现该包保留的全部候选，核对像素与 PNG 字节。使用 Pillow 版本记录在复现报告中。
- `verify_source_package.py` 可核验 ZIP CRC、全量条目 SHA、文件大小和清单完整性。
- 原始图与完整工具返回中的图像逐字节对应；角色卡、历史原始身份图与已生成风格参考均做来源 SHA 比对。本包不额外收录商业原版参考图或商业图集。

## 赫莲·金（HEL）暂缺

本批 HEL 未生成，generation_calls = 0，不计作第四张成功头像，也不以旧图代替新稿。

当前人物卡明确写：“不写成权威大师；她的尺只量本件。”历史独立 QA 则记为“旧图成年男性外形、红工作衫皮围裙和腰小工具保留；源卡未定义的性别外观不反写为故事事实。”锁定历史母版是后梳灰缕发、短须成年男性，与当前卡的女性代词有真实冲突。

B 包的 `held_hel_text_evidence` 保留原文角色卡、历史 QA、冲突说明及来源哈希。其原始 manifest/SHA清单是生产文件存证，其中列出的图像被明确排除，因此不能把它们当作该文本摘录目录的完整性清单；应使用外层 package_inventory 与 PACKAGE_SHA256SUMS。HEL 的旧 PNG 与风格参考 PNG 均未复制入包。等待用户确认按现卡女性身份重绘还是另行调整设定，未擅自改卡。

## 已知边界

- 这些是高分辨率 imagegen 经最近邻缩放、二值透明与无抖动量化导出的候选，不是原生手工逐像素终稿；32 色为临时候选上限，并非全局锁定调色板。
- EMO：成熟大脸、短颈与完整帽耳成立；少量亮眼白、帽纹仍偏细。
- KIEN：宽厚下颌与成熟敦实感已改善；浅发平行细簇及略急下弯嘴仍保留。
- KONA：内眉放平、短颈窄领改善，暗波发短须深蓝领身份成立；仍略谨慎眉/颈斜亮面及少量细亮发带。
- 未集成游戏，未实机验证；独立候选通过不等于原生像素终稿验收或用户美术终审通过。
- 未改旧图、人物卡或 Mod 代码，未 commit 或 push。
