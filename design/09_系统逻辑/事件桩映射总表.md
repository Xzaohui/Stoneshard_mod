# 事件桩映射总表

把 [[全库条件流投影]] 与 [[野外对白条件流]] 的每个节点映射成事件桩（共 1807 个）：命名、触发、读写的状态键与冷却。数据在 `research/event-stubs.json`；本表不声明真实引擎事件号——引擎号在实现阶段分配。

**约定**：

- 事件名 `evt_<脚本>_<节点>`，ID 中的 `-` 与 `.` 换成 `_`
- reads/writes 必须是 [[状态键映射总表]] 里的键；写键只由结算/回执类节点写
- cooldown：入口、结算、回执类 once；hub/any 类 repeatable
- 本表不声明真实引擎事件号；引擎号在实现阶段分配

## 与实现的关系

- 引擎实现按本表建事件：读键判断、写键记录、冷却控制重复；节点台词与守卫仍以各台本与条件流为准。
- 写键只出现在结算（`resolve_*`）、回执（`callback_*`、`receipt_*`）与授权（`consent_*`）类节点；hub 类只读不写。
- 未做：真实引擎事件号、触发距离与作息、存档字段名与迁移。

## 边界

- 本页是实现用桩表：不含奖励、不含数值；不改任何台本内容。
- 桩名可重排、可合并，但读写的键与守卫语义不得改变；改动须回写本表并重跑校验。
