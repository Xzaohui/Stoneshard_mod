# 人物_FX-MN2_锉珥

**工作**：矿车修理工，常在 `rumor_mine2` 一带。地域见 [[区域_R06_无名修院山地]]。

**体貌与随身**：四十来岁的男人，腰带上挂着小锉与短钳，耳朵后面夹着一小截铁屑；说话时敲轨。

**口吻**：先敲两下再开口；谈到深段就压低声音。

**知情边界**：哪节轨下沉了几指；哪根支撑是新换的。不替矿主认领车件；不下最深那段。

当前对白见 [[台本_FX_野外人物对白]]（中英对照，含关联台本 [[台本_DT15_封存之后的巡查]] 的先做/后做与完成前后回访）；本卡不新增奖励、不替他人授权，拒绝有替代出口。
