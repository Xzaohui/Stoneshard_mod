# 世界背景与译名

## 背景口径

奥尔多是主要舞台。外部资料描述王位争议、战争后停战和地方破坏；城市联盟、王廷、灰色军团是政治主轴。势力 Wiki 明确带有过时警告，下面的政治背景属于有版本风险的资料摘要，不能视为本地当前对白全量核实。[势力资料](https://stoneshard.com/wiki/Factions_%26_Settlements)

城市联盟以布林为重要中心，王廷维护王权，灰色军团与平民反抗有关。细节如继承合法性、领袖身世和某城控制权保留核验。原创只描写各方在边地的代理人，见 [[势力关系总览]]。

## 本地书籍里的世界

- lorebook_magic：魔法操作被比喻为蒙眼摸索危险装置。知识残缺、代价和不可靠性是设计约束，不构建安全无限的魔法工业。
- lorebook_eidolons：书中讨论身体、理智、灵魂与神性等“本原”；属于世界内思想与宗教解释，不能自动成为客观宇宙定律。
- lorebook_hieron：圣会有层级、修行与解释经典的传统；奇迹记载是书中记述。原创教会支线允许慈善与权力冲突，不把整个圣会等同邪教。
- lorebook_bronza / nistra / skadia / jacinth：大陆存在多种文化与政体。第一期只用商人、文本和贸易线表现域外，不做大陆全图。
- lorebook_gems：宝石、古仪式与知识传播并存；普通紫水晶不能因此视为主线晶石。

证据定位见 [[本地安装与证据]]，人物可误读这些书，叙事须显示其局限。
