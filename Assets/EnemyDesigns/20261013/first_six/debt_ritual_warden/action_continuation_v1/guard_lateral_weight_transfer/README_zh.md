# 债契仪式看守：侧移换重心

本目录为一张原创独立动作关键姿势，使用内置 image_gen 首稿一次，未使用修订。完整逐字提示词、真实工具参数、完整原工具返回（含base64原图）、raw、透明选图、浅深合成、来源、QA与manifest均保留。透明选图与raw字节一致，未清理alpha或重绘身体。

工具原图大部分主体alpha约253；可见性以正确RGBA合成判断，隐藏RGB和低alpha背景不能当作可见损坏。

相邻对照只用旧选图等比最近邻排版，统一30%缩放，不按每张bbox缩同高；仅展示阶段差异，不证明精确脚底锚点或连续动画。尚未制作完整循环、GIF、装备合成或引擎运行验证。

来源快照保留上游当时状态，部分旧manifest可能写pending或selected=false，当前选择依据上游独审/FINAL与catalog交叉核对；不改冻结旧文件。

包内脚本reference用于审计本次项目版式和封包。rebuild_previews.py可独立从本目录工具原返回重建浅深预览，不改已有raw和透明文件。
