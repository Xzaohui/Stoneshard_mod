# 库奇（FX-BUR）基础动作

2张独立全身日常静态动作，均为内置imagegen首稿；0修订。

- 右手握稳肩前钩杆背带：右手收至画面左肩前、锁骨下方，金属带环上方清楚抓原棕背带；左手仍扶腰旁原绳卷上部，唯一钩杆左上到右下完整斜背。
- 左掌低托腰间旧绳卷：画面右侧左掌在绳卷最低外缘下形成宽托底接触，卷孔与原腰挂关系保留；右臂自然下垂，钩头左上及杆尾右下仍完整背载。

保持已审母图本人比例、衣装和原物件侧别。仅alpha≤8及隐藏RGB清理；无人体编辑、拉伸、量化或插帧。
完整工具返回包含image_url payload。raw与返回payload逐字节核对。
source_hashes与sources保留母图、人物卡、对白、计划与来源SHA。全批规划来源另在联合交付planning_sources。
仅可逆美术概念；不代表连续动画、原生精灵、装备兼容、碰撞或游戏运行。
