# 莉葵：按接近头/其余身体1:1要求做的结构修订

本轮只改单人中性正面，不扩人物/方向。v1、v2及旧177保留。当前为**独立逐行核验认可接近1:1的结构候选**，不是原作风格或游戏验收通过。

## 为什么重做

v2实际可见颏在y16，顶4/底37，头13行、其余21行。v2上次只改善脸部与包带，没有解决用户的新头身反馈。不能把短颈或发辫末端当颏，不能以同一35×44画布证明比例一致。

## 来源和具体做法

- 身份仍为 `TRADE-NPC-LIQUI`，同一名往返两地采购人，无新身体、款货、库存、收益或成交。
- 采用已保存的高分辨率新重绘概念 `../liqui_structure_concept_v2.png`，不是旧177，也不把已经缩成13像素高的脸拉长。
- 实际查看高分辨率图后，取x215..901、头部y124..643，最近邻采到20×17；身体y644..1353另采到20×17，分别放到研究画布(8,4)、(8,21)。生成概念的精细眼睛不直接当native眼睛。
- 使用原18色母palette，再进行155次显式编辑操作，涉及153个不同坐标，净变化153像素。合并额颊，恢复小眉/单像素眼/鼻/口、下颌和真实颏；衣领缩颈；单闭包、包带、暗腰带和双空手重新分区。
- 现有可见17色，没有额外生图或安装软件。所有逐步RGBA前后值在 `pixel_edit_log.json`。

## 作者标线与待独立核验

坐标零起算、范围含首尾：

- 头顶y4；下颌y19肤色4像素宽；**真正可见的皮肤颏**y20约3像素宽。
- y21仅1像素短颈，旁边为绿衣领；颈归入其余身体，不算头。
- 发辫垂在观者右侧，不用于头部高度。
- 脚底最后不透明行y37。作者目标头4..20=17行、其余21..37=17行。
- 研究画布35×44、实际全身alpha框19×34。宽度按脸颅与短辫剪影处理，不以填满20px为目标。

独立审查已实际20x逐行复核：y19下颌肤色x15..18为4像素，y20三像素肤色被深色边包住可读为收尖颏，y21仅x17皮肤夹在绿领内。主读17:17；保守把y20视为颏颈过渡时16:18，也接近1:1。主颅宽16、肩宽18（排除辫），无需继续增宽。独立意见仍指出较正面近对称暖色脸、冷暖分区弱、颏偏尖；结构比例改善不等于整体风格终审通过。
