## 阅读顺序

1. `comparison_originals_1x.png`：Before、A、B、Gunda、Bert同画布坐标、相同脚底，原生倍率。先看游戏尺寸的读形。

3. `face_closeups_10x.png`：相同顺序，头部最近邻10倍。放大不加细节。
4. `sela_face_A_native.png` / `sela_face_B_native.png`：35×44透明输出；各有8倍透明预览。

原作只用来比较五官的组织和短标记，没有从Gunda或Bert采样任何颜色或复制任何像素。

## 两个小样

- A（24像素）：尝试很轻的3/4转面。增加1像素远眼，把鼻梁明色放在两眼之间；近眼保紧凑暗锚点，远侧眼眶/面颊用暖色面交代。保持原发际和颅体，未把整头转向。
- B（14像素）：保持单眼侧向读形，眼尾由纯黑转为暖深棕。减少长鼻的水平凸出，增加一枚暖色嘴标记和连续的颊部阴影。
- 两者都只去掉鼻投影最外侧(10,17)与其黑色下缘(10,18)这2枚不透明像素；下颏y20、暗颏/短颈y21逐像素不动。鼻其余边缘不迁移。
- A近眼是两枚纵向深棕形成的小眼窝，B保单行；没有白眼珠高光或妆线；皮肤沿用原三色，与手部同一组颜色。没有新颜色或整体提亮。

## 生产者实看意见

已实际查看原生1x及10x局部：初版B更克制，A水平眼线略低垂。根据独立审看进一步将A近眼收成两枚纵向深棕、分开鼻下与嘴标记，并在A/B嘴旁恢复亮肤打断横带。复看后A五官层次更易读；B保留原侧向身份感更强。转面的说服力仍受固定发际和原轮廓限制。不能用“改了多少像素”证明更美观。应以独立审看及用户判断选稿，不自动采纳A。

## 边界与核验

`face_allowed_envelope.png`是预先显式定义的允许局部范围，`face_mask_A.png` / `face_mask_B.png`是实际变化像素。`pixel_edits.json`逐像素记录坐标（0起）、RGBA前后与理由。`palette.json`记录沿用色板及没有新增色。

`QA-producer.json`包含预定允许范围外逐像素相等与哈希、实际mask外相等、alpha、顶y4/足底y37、末下颏肤行y20保持、所有y13..19之外的完整行相等。`QA-reproduction.json`另验两张native逐文件重现及单一8连通人物。

发髻、颅顶、头宽极值、身体、衣装、腰绳、手与脚均未动；可见总高34像素、头17/余身17保持。保留源文件原始SHA并对revision_1to1所有文件前后检查。未写global或runtime，未安装软件、未push。
