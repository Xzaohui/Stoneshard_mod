# Design Specification

## Project Overview
俉珥（FX-CV3）两种可逆面部表情概念。

## Asset Requirements
- wuer_E1_evasive_about_name：问名回避。只呈回避，不公开或认证姓名，不画洞口图/签名/证词，不代表加入帮派或替其传话；未授权不作N9实名或藏身址公开，伤害与旧缺指不消失。
- wuer_E2_careful_limited_explanation：低声指点。给一段有限信息不等于愿意陪同、保证整洞安全或揭露口令；不公开窝点其他人，不更新成全知换班表，不确认N9结案、证据认证或关系改善。

## Art Direction
本人母图单一身份参照，透明完整全身，清楚粗像素簇。

## Technical Requirements
Builtin imagegen，transparent_background=true。实际工具画布入日志；原RGBA保留，不机械改比例。

## Animation Requirements
独立静态表情概念，不称动画或运行素材。
