# 比例结构引导重绘

适用：内置编辑多次受旧长身全图锁定，文字要求短颈、紧凑身段仍无效时的替代。不是正常人物的强制流程，也不把所有人强卡同一比例。

1. 读人物卡、旧独审、当前 STYLE_DIRECTION，实看旧图。明确应保留的脸、情绪、衣装、道具、站坐姿及剧情边界。
2. 原图不覆盖。用已获授权的像素编辑脚本，在新的版本目录生成标为 GEOMETRY_GUIDE_NOT_DELIVERABLE 的结构草图。按颈、躯干、腿或裙身分段，只改变需要的轮廓；记录切分坐标、缩短量和来源SHA。头脸通常不机械变形。不能把伤腿/坐姿改掉以凑数字。
3. 草图只是非交付几何引导，不是最终精灵。最近邻压缩可能使像素不方、手/书/灯变形、段缝突变，必须实际查看后再输入内置 imagegen 重绘。
4. 重绘要求锁住新的冠顶、下巴、肩、腰、脚位置和整体轮廓，在该结构内修复颈肩、衣褶、手臂/工具遮挡和方形像素簇。脸已正确时明确保留；脸需独立化时单列面貌目标，不借另一人全脸模板。
5. 保存内置原始输出字节，实看完整图、面部、手和道具。量头冠至下巴与余身仅作辅助；自然成年、神态、姿态支撑与职业身份优先。不是比例数字达标就通过。
6. 查真实alpha分布和有色背景：RGBA/PNG本身不证明干净透明，半透明棕色光晕仍是不合格背景。必要时在浅/深底检查；不把检查图当交付原图。
7. 记录来源、原图/引导图/最终图SHA、完整提示词、实际生成输入、测量与限制，并交独审。保留未过版本及历史QA，不自行标用户认可。

## 实例

- Anla：`../anla/rework_v3/anla_GEOMETRY_GUIDE_NOT_DELIVERABLE.png` → `../anla/rework_v3/anla_rework_v3c_raw_imagegen.png`。此前两次文字编辑仍长颈身；结构引导后成年专注脸保留、肩颈与腿自然紧凑，约1:1.6，独审概念通过。像素簇仍比G细。
- Elen：`../elen/rework_v3/elen_GEOMETRY_GUIDE_NOT_DELIVERABLE.png` → `../elen/rework_v3/elen_rework_v3_raw_imagegen.png`。同时改成熟独立窄脸、小眼长鼻/犹疑眉，保低髻与装帧工具；作者实看约1:1.45，独审状态见该目录QA，不由本方法页宣布通过。

这些都是整身外观概念。草图和内置重绘不产生真实分层、原生尺寸、方向动画、锚点、装备换装兼容或runtime验证。机制未知写unknown。最终生成可能仍加细像素或改变比例，必须实看，不能把该方法称作保证成功。

## Rukan透明检查经验

`../rukan/rework_v3/rukan_rework_v3_raw_imagegen.png`的普通预览仍呈棕晕，但用真实alpha合成到浅、深底后无大面积棕晕：透明像素保留棕RGB会在忽略alpha的查看器中造成误判。检查图`rukan_alpha_check_NOT_DELIVERABLE.png`是背景合成证据，不能用它替代透明交付。

选稿`rukan_rework_v3_alpha_safe.png`仅将原alpha<16的极淡/透明像素全通道清零；alpha>=16主体所有通道逐像素不变，raw原件保留。此清理不是通用必须阈值；应先检查实际alpha、背景合成和人物边缘，再按具体图处理，不能拿无脑高阈值破坏手指、发丝或道具。独审已核此图清理范围与双底显示。
