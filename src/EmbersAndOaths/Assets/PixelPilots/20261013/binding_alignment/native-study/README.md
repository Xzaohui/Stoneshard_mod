# 256×256实验像素网格

此目录是独立缩尺与限色研究，不改变上一级1254×1254刚体证据，不规定引擎最终规格。

先将上一级固定A/B层各做一次最近邻缩放：A为87×131，B为77×131。共享20色纸张调色板，另有1色背景；四帧实测均21色，无抖动、无半透明。之后只整数平移，A固定(34,63)，B横坐标141、105、70、34，纵坐标63不变。最终右侧下层条宽10px。

沿用A的采样孔mask模板，B缩尺后的孔已相同，无须新增alpha修补（实际fill=0、cut=0）。孔局部bbox为[7,22,12,26]、[7,64,12,69]、[7,106,12,111]；中心距离42.5与42px不随帧改变。最近邻取样令上孔5×4、其余5×5，说明轮廓确实因缩尺改变；不伪称保持了原1254图的全部几何细节。原始B的7个alpha修订仍属上一级已记录的前置修订。

实际查看frame_03.png原生256、final_nearest_4x.png、spritesheet.png与holes_nearest_8x.png：三孔和下层条可辨，B移经A时孔透出A纸，末帧重合后透出背景。图层哈希恒定，独立数组合成与Pillow合成完全一致。此为低分辨率制作方案试验，不是原生游戏精灵验收；轮廓、纸纹和颜色均受一次取样/限色影响。

复现：

    python build_native_study.py --out /tmp/binding-native-rebuilt

输入自动取脚本上一层layer_A.png和layer_B.png。查看manifest.json中的来源SHA、全部20色、坐标、孔bbox与验证结果。
