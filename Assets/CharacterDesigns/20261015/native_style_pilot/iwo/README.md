# 伊沃原生尺度风格试制 · 2026-10-15

## 结论

- 头像 v1：保留为风格候选，74×100，31个可见RGB色，二值alpha。1x可读，帽子为灰褐软布，眼窝暖褐化、鼻颧面保留。眼白偏亮、脸部占画面比原生参考稍小，尚未用户验收。
- 地图 v1：失败过程稿，35×44，19色，实际可见19×42。身形过长窄，面部细节崩失。
- 地图 v2：唯一一次定向修订后仍未通过视觉门槛，35×44，17色，实际可见21×40。帽型/发色/灰绿外衣与头像一致，比例有所改善，但双眼暗块及鼻口下颌纵向粘连，1x像素组织不足。
- 不继续消耗生图额度。没有合格地图终稿，没有游戏接入或运行验证。

## 不可混淆的两种完成度

三份目标尺寸文件的尺寸、RGBA、alpha0/255、数值色数预算通过，不等于原生像素美术通过。头像也仅是目标尺度风格候选，不是已验证原生手工绘制资产。

工具输出依次为1079×1458、1120×1404、1118×1407，均含连续alpha和大量色值。builtin imagegen没有精确原生尺寸、palette参数；本轮已经按目标网格提示，仍不能直接控制原始像素组织。候选文件全部如实记录为最近邻缩放和无抖动量化派生。自动palette含若干近似色，并非手工逐色设计。
