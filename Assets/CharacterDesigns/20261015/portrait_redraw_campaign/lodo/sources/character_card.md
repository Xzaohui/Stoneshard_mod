# 人物_ALD-S03-NPC_萝铎

居住 [[聚落_ALD-S03_石礼驿]]；所属 [[聚落_ALD_奥尔德文]]。身份、经历与口吻全部Mod原创。

**日常工作**：接待不同礼仪旅人的驿主。

**动机、缺点与可能转折**：最初用同一礼规维持秩序，还把赞助感谢当人人该说。分开接待会增加她一班费用；坚持某项私人礼规也不能扣普通护理款。她若拒灰色转货，会真失去运商生意，不靠玩家口头劝善免代价。

**生活台词**：「借我一晚屋檐，不必借我整套活法。」

关联台本：[[台本_CS-ALD-02_两种送别]] · [[台本_CS-ALD-03_一件太合身的礼]] · [[台本_CS-ALD-06_往布林的空箱]]；地域章 [[台本_CM-ALD_护甲里面的名字]]。

此人负责本地生活现场与有限观察，不替代台本原当事人的新同意、旧证据所有权和奖励。未亲历的案不能因同在本镇就知；须有具体公开事实或经本人允许的有限回执。已结案只有未来回应，不重开方法。

死亡/缺席时停本人新台词，基础安全可走现有固定痕和事前有限记录；不能让别的住户代该人和解、迁居或签未来劳动。上面的转折是可能弧线，具体发生须满足已执行方法和实际代价，并非走进聚落自动触发。
