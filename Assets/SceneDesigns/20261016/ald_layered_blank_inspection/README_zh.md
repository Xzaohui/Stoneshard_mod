## 六个独立主图层
所有主层及细分子层均为1536×1024 RGBA PNG；左上角(0,0)重合，alpha整理为0/255。

1. `layers/00_ground.png`：完整旧石铺地及前侧返街落脚面，没有建筑或道具。
2. `layers/01_body.png`：完整无顶低石墙、四角木柱与上梁；正面敞开。没有地面、家具或证物，不靠屋顶遮缺口。
3. `layers/02_roof.png`：独立浅单坡瓦棚，整层可隐藏。
4. `layers/03_furniture.png`：空验台与两座独立空料架，不含金属或工具。03a、03b、03c分别给出台、旧料架、新料架。
5. `layers/04_tools_stock.png`：分架旧坯、新料与卡钳/检针，均未烘焙进家具。04a、04b、04c分别为旧料、新料、工具。
6. `layers/05_old_blank.png`：可单独隐藏的关键旧坯，带三个返修孔及两组不同工艺凿痕。

实际叠合顺序：00 → 01 → 03 → 04 → 05 → 02。揭顶只隐藏02。取下旧坯只隐藏05，桌面保持完整。
03/04主层与各自子层是替代用法，不应同时叠加。子层依次为03b→03c→03a、04a→04b→04c。

## 叙事和目视核对
- 低石墙围隔工作声，前侧与左侧留出清楚的普通返街空间；不画港口、炉火或危险作业通道。
- 旧采购坯、新料分架；台上关键旧坯与料架上的普通候选明确分开。画面中的三片/三条只为构图，不定剧情库存或交易数量。
- 旧坯的四凿印、双划痕只是两组工艺署记的视觉候选，不规定某位人物、家族、师门或军需印的正式图案。
- 没有姓名、地址、签字、接收回执、通行许可或结案标志。技术认功不等于公开本人姓名；图中无人物，不替当事人选方法。
- 无顶主体与地面完整连续，瓦棚两侧与柱顶实际贴合；图层真实叠合、台脚落地，关键旧坯未压到柱墙。已目视检查盖顶、揭顶、移除旧坯和六层拆分图。
- ImageMagick独立重组与最终揭顶透明图逐像素AE=0。该结果只验证图片合成一致。

## 过程与边界
六张初稿均由内置`image_gen`绘制，本处未追加生图修订。`raw/`保留原始PNG，`prompts/`保留完整提示词，`sources/`为只读来源快照与参考图。只用ImageMagick做选区裁切、alpha阈值、最近邻缩放、整数平移和source-over叠合，实际参数见`TRANSFORMS.txt`。
