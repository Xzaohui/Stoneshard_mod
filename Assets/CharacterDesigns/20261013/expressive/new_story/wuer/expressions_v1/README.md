# 俉珥（FX-CV3）表情概念 v1

问名回避、低声指点，两张独立全身透明像素概念。

- selected/：原始RGBA直接选稿，与raw同SHA。
- raw/：所有生成原PNG及完整工具原返回；prompts/保存真实发送全文和参数。
- review/：逐图浅深合成检查与中文浅深板；sources/为输入快照和SHA索引。
- generation-log.json：输入、prompt、调用时间、工具返回、输出路径与SHA。
- manifest在独审前冻结；独审记录与FINAL_STATUS在其外绑定最终状态。

不回写人物卡，不断言任务结果，不代表原生帧、装备、动画、游戏运行通过。性别未明沿母图中性成年可逆外观；不以旧伤定位提案补定canon。
