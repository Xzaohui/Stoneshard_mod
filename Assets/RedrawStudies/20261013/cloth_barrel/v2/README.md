# 候选清水容器 v2：当前像素结构与材质修正

此版对应独立目视反馈：v1主体大平色过多、深箍太宽而像塑料、布盖像硬盖。问题在当前图像结构，不能留给引擎光照解决。v1所有文件保持不变。

## 本次单次目标修正

- 木身：保24×24主体边界和底部y=28，木条左右弧形收束，用少量断续阶梯短簇形成木板/磨损节奏。没有从原版桶拷贝像素。
- 铁箍：前沿缩到约两像素，以窄上缘、暗下缘和有限冷灰亮点区分金属，去掉v1大块黑塑料带感。
- 布盖：偏左浅亮、偏右折阴、中央小塌折，布边非对称；外轮廓预算仍27×26。布仍覆盖桶口，不显示内容物。
- 保一个左前小扎结，不增订单签、标签、文字、医药标识或任何合格/交接状态。
- 调色由14色放宽为17种不透明色，仍为二值透明，无抖动算法；有组织的小簇优先于追求“零孤点”。

## 目视结论

已实际查看`v1_v2_reference_comparison.png`和三背景`native_background_QA.png`。v2相较v1确有可见改善：金属由宽黑条变窄弧带，木身从大平面变为随桶身收束的木板短簇，布盖更像有折痕的布；新桶与历史桶的左右明暗体积关系更接近。此结论只说明本次修正有效，不代表最终风格已经通过。布褶与扎绳在1×仍很小，整桶仍比历史参考略规整；需根代理独立目视。
