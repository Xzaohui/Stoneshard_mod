# 状态键映射总表

把全库脚本与回执映射成实现用状态键（共 1393 个）。键名与取值由源文件确定性推导，见 `research/state-keys.json`；本页给出约定、族计数与逐项清单。

**约定**：

- 键名把 ID 里的 `-` 换成 `_`（如 CS-BRY-01 → CS_BRY_01）
- `resolve_*` 在结算前为 `none`，结算后取唯一路线/选项键；不回滚
- `callback_*` 只表示该回执已播过；不重复给奖
- `paid_*` 只记一次费用；`consent_*` 记本人或限权授权
- `presence_*` 四态：present/absent/dead/refused；缺席不代播新句
- `receipt_CX##` 为跨任务回执；接收者与时机见 note

|---|---:|---|

## 旧档迁移与缺键口径（OI-03 定稿，2026-10-14）

- **引擎键名＝`EAO_`＋登记键名**（[[引擎键名前缀与遗留键登记]]）：`encountered_N2` → `EAO_encountered_N2`。首批 [[试点批次总表]] P1（N2）五键已按此落地进 0.3.2 候选。
- **取值存储**：枚举类（`resolve_*`、`presence_*`）存字符串；二值类（`encountered_*`/`callback_*`/`consent_*`/`paid_*`/`order_*` 的真假键）存整数 1＝真。
- **缺键读取口径**：`resolve_*` 缺省 `none`（未结算，读档后仍为 none，见 [[试点批次验收场景N2]] T06）；二值类缺省假；`presence_*` 缺省 `present`。读取从不回写、不构成"已知"授权。
- **旧字段不自动迁移**：N1 小样键（`EAO_N1_*`）、旧任务键（`EAO_MQ0*`）、测试传送与开发观察键原样保留，只读不重映射；N1 重制时按 [[N1小样键语义与迁移建议]] 改挂登记键，此前不动。
- **同一脚本不得双写**：N1 小样完整保留样例键至重制；N2 起一律登记键（见 [[键名口径对账]]）。两套键并存于同一存档是允许的（不同脚本族），同一脚本内不允许。
