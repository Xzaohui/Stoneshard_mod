## 为什么重新画结构

batch10/46的旧莫伦长衣、围巾、单药袋身份清楚，但头身及长腿结构不能靠降分辨率修好。新概念先重排大头、短颈、短腿，再在35×44画布独立逐行构造头发、脸、胡须、围巾、衣装与手包。最终native没有对旧板或新概念直接采样缩小：新概念提供造型方向，全部像素由脚本显式定义。

可见顶端y4，眉眼y12–13，鼻y14–15，胡须末y20，围巾/肩重叠y20–24，腰带y27–28，衣摆y33–35，短腿和靴y34–37。胡须不等于解剖头长，衣摆与腿区重叠；没有把16/8/10设为统一公式。闭袋在画面右侧，单条斜带；左右手独立暖色簇，脚底分开。眼睛保留眉下暗瞳与单像素眼白，鼻梁、鼻侧和胡须口部独立。没有复制Frid紫衣、Jurg围裙或Gunda裙装。
