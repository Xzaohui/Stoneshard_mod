# N6 装订孔刚体关键帧小样

本小样专门验证“同一张纸移动时不变宽、不换纹理、不漂移孔位”。它保留原概念图的1254×1254源分辨率，并非最终原生像素精灵，也未接入游戏。

## 结果

- 从batch64第一张并排图各提取一次纸A、纸B。A固定在(168,313)，B依次位于(703,313)、(524,313)、(346,313)、(168,313)。全程只整数平移，无缩放、旋转、重新生成或每帧修补。
- A层尺寸435×657，B层383×657；各层RGBA哈希在四帧间完全一致。最后三孔mask逐像素重合，右侧留下名义52px的A下层边条。
- 孔相对纸层的包围框中心为(46.5,119.5)、(46.5,332.5)、(46.5,544.5)，相邻中心距离213、212px，四帧不变。这里保留原A的不等间距，不伪称等距。
- 初始B孔mask存在极小差异：以A透明孔mask为模板，对B一次性调整7个alpha像素（2个填实、5个挖空）。填实像素用B同一行右侧32px纸纹，2次赋值均实际改变RGB。此为明确的美术修订，不能声称源图孔几何原本已精确一致。
- A所有保留不透明像素的RGB与原图一致；B除上述2个实际RGB变化外一致。分割得到的透明底层不是源图自带的alpha。

## 复现与验证

从仓库根目录运行：

    python src/EmbersAndOaths/Assets/PixelPilots/20261013/binding_alignment/build_pilot.py --out /tmp/binding-rebuilt

已安装Pillow、NumPy、SciPy，无新增安装。脚本默认相对自身位置定位batch64第一帧，也可指定`--source`。运行会执行图层逐字节恢复、固定画布、相同孔几何、最终孔mask重合及第二种数组合成实现的一致性断言。`manifest.json`记录坐标、尺寸、哈希与修订；`provenance.json`记录源台本、两原图、工具版本和产物SHA；`QA-producer.json`记录实际查看与源RGB差异。

背景改为明确的新纯色#392b20，不冒称重建了被纸遮住的旧背景。二值分割保留约1px源背景细边，2倍边条图可见；未制作物理阴影或游戏原生网格。中间帧B孔透出下面的A纸，最终两层孔对齐才透出背景，符合这次独立层试验。原batch64、runtime、全局索引均未改。
