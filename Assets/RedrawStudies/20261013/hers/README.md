## 技术过程

新生成画稿的连续三个区域分别重映射为头部16行、上身9行、下身9行。头发/胡茬/颈口有重叠，这不是解剖量尺或引擎规则。x区间一致，未拼接其他角色。透明alpha阈值128；固定20色调色板逐像素最近色，无抖动，实际用18色；全透明像素RGB归零。原尺寸35×44，alpha bbox `[8,4,28,38)`，可见20×34。脚底固定y37，两足底之间有透明空隙。

随后显式修整眼/鼻（避免降采样合成一片黑）、灰发簇、空手与袖分离、钥匙圈/柄、双短靴；每个坐标保留before/after与理由。账簿由新输出独立区域取样为9×6，闭合棕封皮和浅纸沿分别可见，不含字迹。
