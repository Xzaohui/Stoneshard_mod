# 0.3.1 开发观察模式

用于当前 Stoneshard 0.9.4.25 modbranch / MSL 0.13.2.0 安装。运行证据以 `artifacts/dev-runtime-20261013.json` 为准；离线校验不代表实机通过。

加载角色后按 F6 开启，默认关闭。快捷键已核对本地原事件为空；F8沿用现有测试传送。

| 按键 | 功能 |
| --- | --- |
| F6 | 开启/关闭开发观察模式；关闭时恢复原雾层显示 |
| F7 | 临时显示被雾层遮住的画面；再次按恢复，不填写探索格/地点发现记录 |
| F8 | 开关原有世界地图测试传送；开启后地图左键选择世界格 |
| F9 | 显示角色附近实时原生寻路格：绿=空格，红=当前阻挡 |
| F10 | N1新素材与原开发底图对比，仅影响显示 |
| F11 | 旧渡口岸院→钟屋→暗渠→岸院巡览 |
| Shift+F11 | 在N1场景中返回首次巡览出发点 |

巡览在战斗、死亡、地牢、对话、地图界面、转场和回合锁期间拒绝。临时门继承原门 Alarm 7，原生事件4保存地点；不直接调用 `room_goto`、不搬动已创建玩家。记录的 `EAO_N1_origin_*` 仅是返程导航；不写阶段、解法、证据、人物离场、金币或任务奖励。

观察面板只在本次游戏进程内保留。世界地图雾层隐藏不等于该地区已探索，未发现图标仍可能不显示；地表单位的原生可见性和AI规则保持。F6与F8是独立开关，离开开发测试时分别关闭。

面板显示版本、房间名、角色格坐标、世界格和F7/F9/F10状态；`F6 OFF`表示“按F6关闭”。它随角色定位并限制在房间范围内，查看遮挡区域时可关闭观察模式。

加载角色或重建角色数据时观察模式恢复关闭（实测世界格重载和返回地表会出现）；需要继续观察时再按F6。Shift+F11已实测从岸院回到本次出发位置。F8只核验落点可通行，不保证目标世界格没有敌人；实测重载土匪营地会落到营地内并触发敌人警觉。

16张纹理作为程序集资源内嵌到.sml：三房间各四层，加钟/断绳/两张铺盖/钟屋外观。原点与像素内容对照素材manifest逐项校验，不依赖项目绝对路径。钟屋外观暂在面板中作为独立样件显示，其入口与占地尚未安装到岸院。

实测发现铺盖新图与继承的原点击区域未对齐；检查交互时可按F10切回原图。这一批用于实机观察，仍需逐物件完成热点、遮挡与碰撞装配。未接N1时查看铺盖曾无法退出，已补“先离开这里”并实测关闭对话。

自动化复测中一次Shift+F11短脉冲被识别为普通F11，随后从岸院重发组合键成功返程。建议先按住Shift再按F11；组合键持续按压还需人工复核，记录不把每次输入均稳定视为已通过。

构建：`tools/Build-Mod.ps1`；部署：`tools/Build-Mod.ps1 -Deploy`。部署要求全部套件与候选SHA一致，并备份data.win、MSL设置、旧包及完整用户数据；游戏或MSL运行时拒绝替换。回滚不自动还原角色存档。

本轮不把美术观察当作N1剧情全流程验收。所有实机通过项、失败项和未测项单独记录。
