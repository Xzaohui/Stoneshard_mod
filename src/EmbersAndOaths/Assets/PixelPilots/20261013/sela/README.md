# Sela 像素级校准小样 v001

2026-10-13。只试一个人物、一个静止姿态（view01，偏向画面左侧的三分之四面），不是游戏可用素材验收。原始 batch79 v2、其它概念图及全局索引未改；未构建、部署或运行游戏。

## 结果与建议

- **优先审阅 B：48×64**。实际可见范围26×58，画布内宽度占54.2%、高度占90.6%；脚底基准行 y=61。保留较多空间解释发髻、浅袖、披肩和绳圈内孔，适合作后续像素轮廓讨论。
- **A：32×48**。实际可见范围20×44，宽度占62.5%、高度占91.7%；脚底基准行 y=45。试验更小的信息预算；虽然修出绳圈内孔，但袖口、脸和腰部仍比较拥挤，不作为最终定稿。
- 两种画布是可审阅的**实验选择**，不是 Stoneshard 的统一规格。单张 Verren 25×38、19种可见色仅描述那张公开 PNG。这里没有为了凑该数值扭曲比例，也未引用其像素作新角色内容。
- 当前仍继承生成稿的大头、长躯干和卡通化面部比例。真实像素网格、硬透明边缘和限色不等于已匹配原作；需要更多匹配版本参考和实际落地截图才能决定人体高度、透视与最终画布。

## 方法与可复现范围

1. 读取 batch79 v2 原图 SHA。只从边界连通的近中性中亮背景建立排除区域；保留最大前景连通块，避免拿裤子中性灰作简单全局色键。
2. 前景内每个原像素映射到明确语义调色板。每个目标像素格统计前景覆盖率（至少45%），选择前景主导色。没有抖动、误差扩散或背景参与的颜色平均。
3. 保留面积采样 baseline。显式像素修整将头发误分到的皮革色合并为发色块，缩短竖向眼部暗线，以两级绳色明确原有绳圈，不增加新道具；B修去左手下方一个轮廓刺点。所有差异可追溯。
4. 对仅一个像素的独立 alpha 碎片设有过滤器，但本次两个 baseline 实际均无该类碎片被删除。发髻细梢保留；连通检测只作记录和本次回归断言，不能作为未来必须强行连接道具的规则。
5. 固定画布和脚底基准，不用每帧 bbox 自动重居中。此处只制作一帧，不声称完成逐帧对齐或动画。锚点 x 是画布参考中线，y 是最底可见像素行；不是 GameMaker origin，也不宣称锚点坐标一定落在有色像素上。两脚的轮廓有自然高低差。
6. 用最近邻产生整数倍预览；实际查看原尺寸和8倍对照。检查二值alpha、透明RGB归零、调色板子集、边界留白、最底行与锚点一致。实际origin、collision为null，runtime_verified=false。

这是一份**脚本辅助、含明确逐像素修正的制作研究**，并非逐像素手绘完成。自动检查通过只证明所列图像属性；不能证明审美、人物成年感、动画、碰撞或运行兼容。

## 正式接入前

先只读确认拟沿用NPC的真实Width/Height、origin、纹理裁切偏移、碰撞、朝向/动画选择规则，再定正式比例。随后补少量动作帧并统一脚点，制作非部署候选包读回，最后检查同场景站位、缩放/过滤、遮挡、点击和通行。不得凭本试作扩量处理299张概念图。

## C：参考身高预算追加试验

C为32×48透明画布，内容约15×34，足底仍在y=45，偏移(8,12)。原图实际裁切362×827，等比降至34高所得宽约14.9，故取15；没有为了对应Verren披风的21像素宽把Sela横向拉胖。整数取整会有微小比例误差，不能把像素取整称作数学上完全等比。

`c_32x48_reference_budget_idle_view01_f000.png`保留褐色发髻、青色披肩、浅色袖口、裤子和靴。脸只剩一个暗眼点，绳圈缩为约3×4的符号，内孔只有两像素；因此卷袖的结构和绳圈材质不能同B一样清晰。此实验回答“34像素可见身高时还能留住什么”，不把C自动选成最终素材，也不把B的58像素身高冒称原生。实际查看了Verren原尺寸和最近邻8倍图：其披风/头套/胡须分配与Sela不同，不能照抄轮廓或推断全部NPC的规格。

新增 `comparison_v2.png` 三列同为8倍预览。A/B原图、baseline、预览及 `comparison.png` 均字节保留，原A/B验收结论不改变。C另有baseline、逐像素编辑清单，并追加manifest检查；独立QA另外记录。
