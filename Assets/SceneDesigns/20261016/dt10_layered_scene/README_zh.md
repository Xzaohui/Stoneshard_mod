## 同画布交付
所有层都是 **1536×1024 PNG**，左上角 (0,0) 对齐。底图不透明，其余四层为真实透明 RGBA；交付透明层 alpha 为 0/255。

1. `layers/00_ground_forest.png`：地面、道路、林缘、草丛与自然石块；没有岗棚、血槽、桶或足迹。
2. `layers/01_shelter_body.png`：无顶岗棚完整主体，含背墙、顶框、立柱、斜撑、蓝布侧挡、固定长凳、暖灯、石脚和紧贴结构的少量地面。被屋顶遮住的上方结构已补画。没有槽桶或狼足迹。
3. `layers/02_shelter_roof.png`：单独木板棚顶与三块压顶石，没有立柱、墙、灯或地面。
4. `layers/03_trough_bucket_stain.png`：石槽、一个空木桶，以及槽内和出口附近的旧褐色弃血残痕；不含足迹。
5. `layers/04_wolf_tracks.png`：八枚狼足迹的单独透明地面贴花层；从槽出口附近绕过槽体，向上方林路引导。

真实 source-over 合成顺序：底图 → 足迹 → 槽桶旧痕 → 岗棚主体 → 屋顶。揭顶只隐藏第 2 号屋顶层，其他层完全不变。底图中微弱暖色反光属于这版夜景气氛，不是独立灯光开关层。

## 绘制与检查
- 使用内置 image_gen 绘制五类图层；共八次生成。底图、屋顶、足迹各进行一次必要修订，主体和槽桶各一稿。
- 底图初稿误带一枚足印，第二稿移除；屋顶修订降低长边斜率；足迹修订改为小尺寸可辨识的完整暗色掌垫轮廓。
- 生成后只用 ImageMagick 进行透明边缘整理、最近邻缩放、选区裁切、整数平移和真实 alpha 合成。没有 Python 绘图，没有用最终整景再次生图冒充图层叠合。
- 实际打开查看了初稿、修订稿、完整盖顶/揭顶图、檐口/柱脚、槽桶落地与线索路线局部。棚顶覆盖柱帽与顶部框架，没有独立悬空间隙；揭顶后背墙、长凳、柱梁完整。槽和桶在同一地面上，旧痕从槽出口延续至地面。足迹没有被重复烘焙到背景或道具层。
- 槽的长轴与岗棚前梁方向不同，作为地面上略旋转摆放的独立设施；并非两座必须共轴的建筑。所有对象使用相近的俯视斜角和冷夜/暖灯光色。
- 八枚足迹来自第二稿的七个独立绘制印迹，末枚以同源印迹重新缩放放置。它们是代表性环境线索，不是动物步态或碰撞路径模拟。
