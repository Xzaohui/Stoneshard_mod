# 六类敌人参考研究（尚未开始绘制）

调查日期：2026-10-13。范围：公开官方开发日志、公开游戏图与项目已有设计。此轮只准备参考；必须在新剧情人物阶段完成、主任务明确切换后再画敌人。**本目录没有生成敌人图、原版安装包导出、运行精灵或游戏实现。**

## 证据口径与分类结论

- **官方一手**：Steam 的 Stoneshard 开发者公告及公告内图片。历史日志用于视觉语言，不能冒称已与本地 `0.9.4.25-modbranch` 逐帧匹配。
- **二级**：stoneshard.com 上署名 Official 的 wiki 仍按社区整理资料使用，尤其是具体敌人名、阵营字段和数值。本文不抄用它的战斗数值。
- **项目已有设定**：下面所列设计文件为 Mod 原创草稿或原作基线摘要，不代表已实现。
- **待设计提案**：六类只是用户要求的美术分组，并非六个已证实独立原版阵营。
- Proselytes 在官方 2022 公告中明确属于吸血邪教；2025 年底公告说明其从人形信徒向兽性异化者发展的统一路线。“吸血鬼 / 邪教”宜在美术上分成肉体异化与人形仪式成员，不能声称二者是原作互斥阵营。
- 社区 wiki 有 `Rebel`，阵营字段为 `Brigand`。不能由这个敌人名反推原作政治叛军、灰色军团已有统一现成兵种表或制服。
- 僵尸参照 `Restless / Putrid Restless`；幽灵参照 `Wraith`。`Skeleton / Risen` 的露骨甲胄谱系、`Ghast` 的亡灵施法者谱系不自动归入僵尸。2023 混合陈列图必须按角色区分，不把左侧骷髅感施法者当腐尸模板。

## 共同画法与验收方向（原创建议，不是原版硬规格）

1. 先做黑白轮廓，正常人形以 R01/R02 以及已有 NPC 参照为尺度锚；头、肩、手持具、双脚必须在原生观察尺寸仍读得清。现有 wiki 人形画布约 26×33、37×33，包含武器与透明边，不能直接等同所有敌人的规定尺寸。
2. 正常人形沿现有 NPC 的大头短身像素比例；怪物允许改变身体结构，不能把所有敌人统一套成小孩比例或八头身写实人物。看图不足以规定精确头身比，实际绘制后再按头顶—下巴—肩—胯—脚底量测。
3. 脸不做统一黑条：人类用眉眼暗块、鼻面与胡须分组；腐尸保留面部组织；幽灵用暗眼窝与冷亮额/颊；吸血异化者以嘴、颌、耳或颈突出一个焦点。
4. 底色保持布灰、土褐、锈铁、灰肉；血色与冷光只是局部辨识点。魔法只在幽体和异化类别中增加，避免所有阵营霓虹发光眼、飘带和满屏粒子。
5. 每类第一轮只做一个主轮廓，必要时再做一个对照，先比 6 个主轮廓再扩量。未来静态概念不是可用动画；方向、动作、碰撞、锚点、命中受击与运行验证仍需独立制作。
