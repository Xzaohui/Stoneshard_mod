# 人物_YOS-S01-NPC_梅蓓

**日常工作**：迁来的夜织工。

**动机、缺点与可能转折**：为了留下曾把自己的技术说成只是照师傅做，后来发现孩子也被当成无名代工。分署续作会招来旧户冷脸，独立离坊则失稳定赊粮。她不是只等玩家解救，可以拒公开个人旧史并自己选承担哪项损失。

**生活台词**：「夜里看不清名字，看得清是谁把断线接上。」

此人负责本地生活现场与有限观察，不替代台本原当事人的新同意、旧证据所有权和奖励。未亲历的案不能因同在本镇就知；须有具体公开事实或经本人允许的有限回执。已结案只有未来回应，不重开方法。
