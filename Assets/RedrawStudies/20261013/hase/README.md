# 哈塞单站姿近1:1结构研究

`BRY-NPC-HASE`，原创成年医药商品代理。保深橄榄商衣、棕斜包、胡须与单个闭合瓶。不是原作药师，不表示诊疗、疗效或交易结果，陶芮没有重画。

## 文件
- `concept_v1_unapproved.png`：内置 image_gen 结构生成原稿，保留，不是native成稿。
- `concept_v1.prompt.txt`：完整生成提示词。仅以已实看的原生接触表作风格输入；旧130整图读图后以文字限定身份，未作为生图输入。
- `hase_native_v1.png`、`hase_native_v1_8x.png`：35×44研究画布与8倍最近邻。
- `hase_old_native_originals_comparison.png`：旧哈塞、重绘及Bert/Jurg/Frid原生并列。
- `hase_native_landmarks_20x.png`：原生逐行/列坐标和地标线。
- `pixel_edits.json`：全部221次像素操作的坐标、原色、新色、理由，以及调色板、完整最终字符网格。
- `manifest.json`：来源、路径、SHA-256与生成方法。
- `qa.json`：实际读图、二值alpha、连通性、重现及限制。

## 头身检查
头顶y4，胡须遮挡下的解剖颏估计y19–20，短须末y22，足底y37。头16–17行、余身18–17行，接近1:1；绝不把须末y22当颏。估计颅宽15–16px，颈嵌肩。35×44/可见34px只是这一候选和参考的研究尺寸，不是引擎统一标准。

这一步不是只缩小旧图：先image_gen重构，再将生成源头/身区域映射到native画布，随后逐像素整理发、脸、布、包、封瓶和手。`build_native.py`从生成源确定性重建，`build_comparison.py`重建并列，`validate_native.py`复跑并核对同一SHA。预处理中间图保留为研究痕迹，native_base等不作为交付候选。

视觉观察：大颅宽与短颈、紧腰短腿符合本次方向；双眼/鼻与胡须可分。袖、皮手与单瓶色块可分，去掉现代翻领和马甲细层。脸部仍简化、胡须下颏位置有估计区间，需用户审美复核；原生风格/生产验收均未宣称通过。参考为社区原图，未与本地安装逐项核对，版权归原作，仅用于研究并列，不入运行包。没有新增方向、动画、运行验证或global/runtime修改。
