## 复现与校验

Python 3.12、Pillow 12.3.0。在解包目录运行：

`python reproduce_candidates.py --output 一个尚不存在的新目录`

脚本读取同包 `portrait_redraw_campaign/` 内人物完整 raw 与回包，独立复现所有历史候选，逐像素和 PNG 字节 SHA 比对。A 包复现6张（卢绫3张、诺妲3张），B 包复现5张（赛洛3张、娜娅2张）。输出 `reproduction_report.json`；复现通过不代表娜娅视觉通过。

`python verify_source_package.py 源包.zip`

脚本校验全部 ZIP CRC、成员精确清单、每个清单成员 SHA/CRC/大小与 `PACKAGE_SHA256SUMS.txt`。所有归档均已实际解包后运行复现，11张历史候选字节完全相同。`portable_reproduction_verification.json` 保存该包复现结果。

`build_delivery.py`、`package_sources.py`、`make_freeze_gate.py` 是原仓库交付制作记录，依赖完整 campaign 和本批独立 QA；解包复现只需前述两条独立命令。原始生产脚本留作追溯，请勿在冻结目录直接运行会写文件的生产脚本。
