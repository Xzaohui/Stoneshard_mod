## 构建与安装

本地构建需自行安装Stoneshard及ModShardLauncher，按项目文件的`MslDir`指定本机MSL目录；现有依赖快照为MSL 0.13.2.0。原素材参考目录`stoneshard-assets-sample/`仅供本地使用，图片概念稿不是可直接投放的地图。README中指向`artifacts/`、`backups/`的历史验收记录属于本机文件，不随Git上传。

```powershell
./tools/Build-Mod.ps1          # 构建、真实SML打包、候选读回与检查
./tools/Build-Mod.ps1 -Deploy  # 检查后完整备份并部署；游戏和MSL须退出
```

游戏目录：D:\SteamLibrary\steamapps\common\Stoneshard，本地0.9.4.25 modbranch、MSL0.13.2.0。包部署到msl/Mods/EmbersAndOaths.sml，保留组合定向更新data.win。占用文件时暂停，不强制结束用户程序。

MSL界面重建读取用户确认的原始vanilla.win，勾选所需原Mods及EmbersAndOaths后输出data.win。不要读取已补丁data重复叠加，以免o_msl_timer重复Create错误。.sml含真实128×128PNG图标，经本地MSL读取验证，不是DLL改后缀。

## 测试

### 当前测试入口

重启游戏，回到商队所在的世界格，鼠标点击「绳匠玛拉」。前置为原版《葛文涅尔的答复》完成、商队可用。接受委托后，附近出现标有「旧渡口堤道」的入口。不需要旧迟信、抄本或海关入口。

新开篇从失踪守夜人开始，包含现场矛盾、人物解释、两条可执行路线和不同回访；计划执行前可改，执行后冻结。沿用原生NPC对白、门、接近、保存与转场。

<details>
<summary>验收路线（含剧情剧透）</summary>

1. 找玛拉接取，到旧渡口，可先问追索人托雷。
2. 查看东侧「断绳的钟架」，进入钟房查看「角落的铺盖」，分别选择查看。两处都须实际观察。
3. 找伊沃，追问钟声会带来什么；选择暗渠或公开交涉。
4. 暗渠路线：走钟房东侧通道，到蕾雅处明确确认撤离。公开路线：回桥头找托雷，明确确认家属债票作废、伊沃留置。
5. 未执行时可回伊沃处改计划；执行后不能改。对应角色离场或留置，托雷反应不同。
6. 从断桥西侧「返回商队」回实际出发点，告知玛拉；可追问她起初的隐瞒，两结案对白不同。
7. 分别验收退出保存、睡眠、重载和重访，确认状态/选择不回退、不重复结算。

</details>

### F8测试传送与开发模式

0.3.1完整开发按键见 [开发观察模式说明](tools/DEVELOPER-MODE.md)：F6总开关、F7临时揭雾、F9寻路格、F10素材对比、F11场景巡览、Shift+F11返程。F8地图传送独立开关；测试结束需分别关闭F6和F8。

F8切换 → 打开大地图/日志地图 → 左键点击世界格。初次关闭，已有角色沿用已存开关；关闭恢复原交互并取消待处理请求。右键标记、中键拖动、滚轮保留；不推进任务或发奖励。剧情NPC用鼠标。

保留0.2.3原生占位玩家落点修复：当前世界格可重载恢复，无可走格原转场回退。新剧情场景没有大陆单独方块，使用「旧渡口堤道」入口。真实移动、往返、存读档仍按玩家证据验收。

## 场景与美术

新增三间1040×780场景：断桥两岸与窄堤、钟房及侧通道、折返暗渠。地面和原生碰撞由同一26像素格定义，不使用海关整张背景/前景；复用原生命周期控制器与少量原素材。

原创透明钟架 [night-bell-v1.png](src/EmbersAndOaths/Assets/night-bell-v1.png) 保留。0.3.1另内嵌16张N1 HD2D素材：三房间各四层、钟架、断绳、铺盖和建筑外观样件；F6开启观察、F10切换新素材与旧底图。建筑外观目前只在观察面板显示，尚未作为岸院建筑及入口安装。人物沿用原生精灵，全部地图美术仍在分批制作。

[实际布局预览](artifacts/night-layout.html)展示候选包碰撞和交互坐标，不模拟真实光照、点击与寻路。

## 验收与限制

43项编译指令场景包含旧任务/传送兼容和**10项新剧情场景**；另有8项旧房间兼容、5项地图传送、21项新故事/场景检查、59项开发工具及素材检查，均匹配同一候选SHA。新增检查覆盖未接任务时调查对白的独立退出分支。匿名方法ParentEntry/SCRP/FUNCT、连续CODE分组、原作房间和非EAO代码在写前/读回后检查。

离线原生函数使用测试替身，编译和静态检查不是GameMaker运行。开发工具已进入实机逐项验证，结果、截图和未测项见开发测试报告。完整剧情仍为runtimeVerified=false：所有门/落点、两路线、角色离场与多种保存方式尚未完成全回归。

当前未接入新增大陆世界格、战斗波次、护送AI、金币/经验结算及原生任务日志。结案后的灰堤只是线索，N2尚未实现；整个大型Mod尚未完成。
