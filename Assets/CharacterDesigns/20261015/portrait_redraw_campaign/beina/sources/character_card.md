# 人物_FOR-S02-NPC_蓓娜

居住 [[聚落_FOR-S02_洗砂村]]；所属 [[聚落_FOR_佛尔霍特]]。身份、经历与口吻全部Mod原创。

**日常工作**：洗砂住户。

**动机、缺点与可能转折**：最初只求拿钱换走家人，后来发现拿一次钱可能被写作全体此后不准再说水。有限和解可以接受这次款又保未来问责；拒和解则仍有净水安排但失去快速迁居钱。她不必须留下替整个村作英雄。

**生活台词**：「拿了这袋钱，我明天还是会口渴。」

关联台本：[[台本_CS-FOR-02_洗砂村没有金色的水]]；地域章 [[台本_CM-FOR_金价之外]]。

此人负责本地生活现场与有限观察，不替代台本原当事人的新同意、旧证据所有权和奖励。未亲历的案不能因同在本镇就知；须有具体公开事实或经本人允许的有限回执。已结案只有未来回应，不重开方法。

死亡/缺席时停本人新台词，基础安全可走现有固定痕和事前有限记录；不能让别的住户代该人和解、迁居或签未来劳动。上面的转折是可能弧线，具体发生须满足已执行方法和实际代价，并非走进聚落自动触发。
