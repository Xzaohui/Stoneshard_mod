# 0.3.18—0.3.20 开发模式快速传送（2026-10-16）

用户要求开发 Mod 传送机制，避免靠原生逐格移动赶路。本批服务于世界地图东扩和边缘风格巡检，不新增剧情、奖励或任务前置。

## 操作与保存约束

| 操作 | 行为 |
|---|---|
| F6 | 开/关开发模式；每次启动默认关闭 |
| F8 | 开发模式中直接打开Windows坐标框，输入世界格 `x,y`，如 `41,37`；留空取消。F6关闭后保留旧测试传送开关行为 |
| 地图左键 | F6开启时自动启用点图直达，不需要先步行或施法；地图本身受原生打开条件限制时改用F8坐标框 |
| Shift+F8 | 返回该角色首次成功发起开发传送时记录的房间、世界格和人物位置 |
| F7 | 临时隐藏地图迷雾绘制，用于观察；不改发现网格/字符串 |

坐标框只接受两个非负整数并先检查世界范围；地图目标还须通过边界/房间检查。无效输入、取消及没有返回点时不改变位置。多个连续传送保留首次出发点，失败创建转场不登记出发点。返回是位置转场，不是恢复备份，角色伤势、物品和任务进度不回滚。

传送不执行路径走动、法术或逐格赶路回合。沿用源地点保存事件4→EAO坐标提交事件10→目标加载的顺序，生成结束、正式玩家创建前用原碰撞网格选择可走落点；无落点回本次传送源位置。不移动已创建人物，不清敌人/战斗/输入锁，不直接写玩家文件，不自动结算奖励。原生加载仍可能推进状态倒计时，不能声称完全冻结时间。角色死亡、地下城、动作未完成、对话/切图中仍禁用或等待；非开发模式保留旧F8的战斗限制。

坐标入口使用 Windows 调试输入框；跨平台输入替代仍为待办。[GameMaker 官方 get_string 文档](https://manual.gamemaker.io/lts/en/GameMaker_Language/GML_Reference/Debugging/get_string.htm)注明该接口用于Windows调试。本机0.9.4.25是否正常弹框以实际运行记录为准；保留Steam F12截图热键。
