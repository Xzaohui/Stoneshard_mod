# 米娅转面概念 v1

用户已批准的 1:1.5 v2 原图原封保留，四分之三基准仅以共同 0.60 最近邻比例放入检视板。本次内置 image_gen 各生成一张左侧面与背面，不生成新正面、不做方向动画。

## 文件
- raw/：完整生成原稿，保留原始 alpha 与元数据。
- mia_side.png、mia_back.png：无损重存的单图，像素与原稿一致。
- mia_turnaround_review_zh.png：三视图中文检视板；共同等比最近邻缩放并对齐脚底，不独立拉伸人物或量化颜色。
- prompts/：两张图各自完整提示词。
- sourcehash.json、manifest.json：批准基准、生成稿、检视成品 SHA-256 与技术统计。
- build_review.py：只排版、缩放与计算指标，不绘制人物。

## 设定与边界
成年患者米娅，保留深棕低辫、警觉而疲倦的闭口神态、暗青披肩、米白衣裙、普通叠毯、深棕软便鞋。原图并无腰带或靴子，本组不新增。原源锁较早的 1:1 比例要求已被用户批准的 v2 及 STYLE_DIRECTION 当前条目取代。

背面披肩的朴素 V 形垂坠、后脑编发连接和辫根结构属于最简设计推定，未经用户单独确认，不添加剧情信息。叠毯仍在身体前方，背面因身体与披肩自然遮挡而不可见，不代表丢失或转移。

侧面头至下颏相对余身约 1:1.6，与批准约 1:1.49 存轻微投影/生成差异。侧面眼与发簇有轻微漂移；图为自然成年紧凑的转面概念，不声称逐像素统一模型或精确正交测量。

当前仅概念绘制。没有验证装备部件、遮罩、偏移、目标版原生帧表、方向动画或引擎兼容；未改 runtime、未安装工具、未提交推送。独立结论以同目录 QA-independent.json 为准。
