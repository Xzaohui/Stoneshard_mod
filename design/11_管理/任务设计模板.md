# 任务设计模板

## 新任务最少字段

稳定 ID / 显示名称 / 所属章与区域 / canon / 前置 / 触发人或物 / 必做目标 / 可选目标 / 状态转换 / 线索出处 / 选择与后果 / 奖励唯一键 / NPC 死亡替代 / 物件丢失恢复 / 中途离开 / 计时是否明确告知 / 后续连接。

## 评审顺序

1. 每条前置是否有可到达的产生者；主线前置是否循环。
2. 技能、声望和犯罪是否误成不可逆硬锁。
3. 证据是传闻、原件还是已核实；证据字段不只写“发现真相”。
4. 损坏、击杀、售卖、刷新和再次加载都能产生一致状态。
5. 奖励是否一次性；重复任务是否能刷结局资源。
6. 每个决定至少一个可见短期后果，并在后日谈引用。
7. 截止时间仅自明确接取或确认操作开始。
