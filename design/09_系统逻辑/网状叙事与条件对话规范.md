# 网状叙事与条件对话规范

S62要求多解、人物弧光、交叉后果；本页规范当前51篇台本。全部为Mod原创设计，未改游戏包。[[任务台本总索引]] → [[叙事交叉影响矩阵]] → [[人物弧光与关系转折]] → [[叙事逻辑校验与修订记录]]。

## 先承认第一稿的问题

S61的场面素材有动机与起承转合，但主线大多串联；保密／公开经常被充作解法；人物的认错没有充分进入后续行动；16个日常仍多是搬运、维修与交付。初稿不能算已达成用户要求的网状叙事。S62将128条实际办事路径与74条条件交叉影响写到各台本顶部；旧选择表停用，不能拿两版同时做菜单。

本稿借鉴用户提出的多路径与互相影响要求，不复制《神界：原罪》或《博德之门3》的情节与人物。保留四幕事实推进骨架，不把无序获知一切当作网状；变化来自方法、授权、资源、合作、责任和不同人的生活去向，而非只换终局旁白。

## 会话是状态树，不是自动播完的剧本

| 层 | 进入条件 | 出口与写入 |
| --- | --- | --- |
| 遇见与听需要 | 地点可达、人物可谈 | 只写encountered；主线前置没到仍可听问题，不预发证据与任务完成 |
| 询问、反驳、观察 | 只说该角色能知道的事 | 记录已见事实及问题；未遇到的人不自动成为问话对象 |
| 方法预览 | 对本案已有足够事实；列全部当前可行替代 | 显示成本、负责者、可拒绝者；不足条件给明确缺口，不隐藏默认坏选择 |
| 接受方案 | 玩家明确选方案；所涉本人分项同意 | plan_ID只是意向，可撤；不发奖励、不写resolve_ID |
| 现场执行 | 费用、工具、接应、机关与授权实际核过 | 事实记录追加；失误与伤害留痕，不凭对话宣布人已迁走 |
| 提交结果 | 所有本路线执行条件已过；主线完成前置已到 | resolve_ID写实际方法，任务状态结案；每个ID只提交一次 |
| 后事回应 | 对方拿到有限回执或玩家告知后核验 | X键与本议题revision播放一次；重评未来参数，不回滚历史 |

每个选项支持离开、继续问、拒绝；关闭窗口不默认接受。通过按钮连续点击不能重复发金币、开闸、迁人或结算。玩家的台词要成为可选表达，不自动替玩家选择立场。S61场次是镜头素材，按相关R/X条件剪裁；必须禁止互斥场次同时播放。

## 条件优先级与默认出口

先判死者、缺席、拒绝和未授权，再判终局冻结，再处理伤害与资源冲突、既有生活去向、已执行方法、其他相关回访；最后才是未知事实询问。多个不互斥X可按上述类别逐个呈现，绝不把不同任务写进同一全局if/else使其中一人永远沉默；同一来源resolve只有一个值，因此互斥回访不能共播。

没有相关记录时用本任务本人开场，不说“你曾经做了什么”。每一条X还需要target_receipt(X)或当面有限核验，禁止跨地区全知。死亡／缺席时，中立柜只转述已经登记的事实与状态，不朗读死者新生的情感回答。角色拒谈保留安静／退出节点，不能换柜员模拟其同意。

### 必须替换的基准镜头

- N2 worker_status=dead：不出现活人床前问答或补发授权；用事故现场与原已存医疗记录核事实。N3不请死者认工资。
- N3遇到N2 protected/agency：纳拉不在听审席；妮尔可以讲自己的经手，艾娜只能讲有限代理。不能用一人到场当全员同意。
- N6 witness与N10 sourcehearing：莉德先说自己抄的段，塞娜不能代她署名；凯姆的回答不能压掉她的反驳入口。
- N12 gwynnel_state=dead：撤掉葛文涅尔新答复，用已存稿与独立物证；N13/N15不凭空恢复技术合作。neutral路线则去中立照护点，不播商队对质。
- N17赫斯死亡／逃走：固定账页留原地，不能播放赫斯的新战后独白；招退守卫不等于赦免旧罪。
- DT16 stop：N18只有退出后的普通舒适照护镜头，不播继续疗程或保证治愈；没有选择继续不判负面道德结局。

## 状态与授权字典

所有新增字段是设计字段，尚未映射引擎与存档；不把0.3.0已部署的EAO_N1_*改名。新路线需要单独实现／迁移决策，读旧键不能直接推断用户选过mediation。

| 字段 | 语义与更新限制 |
| --- | --- |
| resolve_ID | 每任务enum：未决定＋本页R键；实际执行后才写，终局后不能重写过去方法 |
| plan_ID | 当前意向；问价、预览、离开不确认；可改而不清既有事实 |
| encountered / known_facts | 玩家见过谁、实际看过什么；见面不代表目标完成 |
| target_receipt(X) | NPC被告知的本案有限事实；不包含未授权住址、所有患者名册或其他支线全局状态 |
| consent(person, subject, scope) | 本人对特定照护、公开、见证或迁居授权；可撤未来参与，不能把已发生事实变成未发生 |
| npc_status / willingness | 存活、缺席、死亡、愿谈；与任务完成和同意分开 |
| callback_seen(X, revision) | 防长回访重播；新消息提高本议题revision，而不是刷新整个任务 |
| history / remedy | exchange_harm、n4_shift_harm、transport_harm留痕；补救另记，不抹责任 |
| obligations | 有限人手、资金、资产与抵押；同一笔运费不能同时付工坊分期和桥工欠薪 |
| episode_DT | unseen/active/resolved/declined；具名冲突不随48/72小时回到unseen |
| reward_claimed | N、DT任务ID，SQ各A/B/C，D不独领剧情奖；回访不再次给钱 |
| ending_snapshot | N17安全桌确认时冻结；以后地方照护、关系和执行可变，终局类型和事实快照不回滚 |

恶意路线另用explicit_harm：明示受害者未同意与具体后果，玩家两步确认后可执行强制行为并留伤害记录，不能伪造consent=true。普通善意迁居、治疗、家书、见证仍要求本人分项授权；不拿“我替你好”放过这个守卫。校验器的consent入参是会话提交守卫简称，explicit_harm时指玩家两步确认，不指受害者同意。

## 顺序、修复与任务网

主线事实完成门槛保留N1—N5、N6/7/8任二、N9—N18。幕内可先访问已可达地点听需要；前事未完成时不播放带未来知识的台词。交叉边允许支线先做再进主线、主线先做再补支线；证据任务是安全骨架，人物关系网不是只按这个顺序说同样的话。

X在目标未结案前改变人手、资金、来源、可用目的地或提问者；目标已结案后只作回访与后续合法修正，例如另撤担保、另补监督。已在场的NPC收到迟到消息立即有一条新回应，下次再打开不会回到旧开场。不要把X设置成任务首次创建时缓存一次，否则晚做支线失去意义。

关系不是统一好感条。船工能感谢获释却拒认可买通规则，护理者能收药却拒替医者免责，病人可拒迁居而支持供给协议。角色还会反对玩家；不能以亲密度让他们违背仍有效的授权或看不见卖人历史。

所有具体边见[[叙事交叉影响矩阵]]；参数冲突保留C01—C06。自动校验只证明数据约束和列明设计场景，不证明文学感染力、原生对白UI或存档安全。
