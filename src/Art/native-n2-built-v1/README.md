# 灰堤原生场景搭建 v1

在已冻结 R01-camp-canal-v2 的像素素材上组装实际房间，不增加概念图完成数量。原发布图片和压缩包不变。

- `layout.json` 是外院占地、建筑碰撞、门与落点、室内道具的单一配置；作为资源内嵌到 Mod。
- 52×38 原生格，26px/格，1262 可走格。三处建筑分别连入现有 N2 房间，原室内路线保留；旧棚子出口经外院返回首次来路。
- 8 件室内布景为非阻挡道具；铺盖属于可走地布，梯子只作陈设，无攀爬、物品、奖励或任务语义。
- 10 张派生/复用 PNG，输入和输出 SHA256 记录于 manifest。地板 alpha 逐格吻合显式占地；碰撞不从图片透明度推断。
- N2 图像在正常游戏模式默认显示。F6 开发观察、F5 面板、F7 临时去雾、F9 碰撞格、F10 地板素材对照、F11 巡览、Shift+F11 返回。

导出：`tools/Export-N2SceneAssembly.py`。像素验证：`tools/Validate-N2SceneAssembly.py`。实际候选的序列化房间、门、落点与 PNG 字节验证：GameProbe `--test-eao-dev`。构建与静态通过不等于实机验收；运行记录另存 artifacts。
