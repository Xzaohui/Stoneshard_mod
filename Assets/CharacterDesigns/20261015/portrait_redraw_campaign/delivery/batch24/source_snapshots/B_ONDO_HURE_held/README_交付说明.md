## 复现与校验

环境：Python3.12、Pillow12.3.0。在解包目录运行：

`python reproduce_candidates.py --output 一个尚不存在的新目录`

脚本从同包`portrait_redraw_campaign/`人物目录读取完整raw和回包，逐一独立复现全部历史候选，核对像素及PNG字节。源包A复现6张（莉葵3、阿洛3）；源包B复现4张（昂朵2、呼蕾2）。输出`reproduction_report.json`。呼蕾技术复现通过不构成视觉通过。

`python verify_source_package.py 源包.zip`

校验全部ZIP CRC、成员精确清单、逐成员SHA/CRC/大小与`PACKAGE_SHA256SUMS.txt`。两个ZIP均实际解包后运行复现，10份历史候选逐字节一致。各包`portable_reproduction_verification.json`记录复现结果。

`build_delivery.py`、`package_sources.py`、`make_freeze_gate.py`、`source_validation.py`、`check_delivery.py`为原仓库交付制作与核验记录，依赖完整campaign和本批独立QA；解包复现只需前述两条独立命令。原生产脚本留作追溯，请勿在冻结目录直接运行会写文件的生产脚本。
