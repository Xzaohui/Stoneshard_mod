# G：单轮内置生图重新设计

- `comparison_C_G_mobile.png`：C/G完整全身6倍和完整头部10倍对照。

- `sela_G_full_sample_native.png`：raw直接最近邻缩至35×44的中间件，不作成品。

## 来源与处理

输入是C作为身份/衣装参考，原版Gunda作为像素密度与成熟女性面部可读性参考；两个16倍最近邻参考在本目录保存。完整提示词为`prompt.txt`。使用内置imagegen而非CLI；原输出另在workspace generated_images保留。没有第二轮调用。

第一版原生化不是再造五官：先将整张raw最近邻采样至35×44，再将y4..20头部映射至原角色八色头部色板并做二值alpha清理，最后接回原角色y21及以下身体。头部逻辑高度17、身体17；衣装手脚原像素不变。没有手工逐点美化生成脸。可重跑`build_g_native.py`。

## 实际审看与限制

已看raw、手机对比与native。raw的完整面部和浅笑比C/F更有生命力，但大眼白/睫毛、平滑子像素细节偏年轻卡通，并未严格满足原版像素风。原生化去除了眼白/新增色，保留更开放额头和微笑；不过眼睛变圆单点、外发髻有变形、鬓边出现零碎像素，尚不能作为成熟最终稿。该候选提供重新设计方向，不宣称漂亮、用户通过或游戏验证。

本轮不覆盖旧图、不改D/E/F、不改游戏包。

## 一次针对性native修复

在初采样后额外执行一次获准的手工像素整理，独立保存为`sela_G_refined_native.png`，未覆盖初版。`comparison_C_Gconcept_Gnative.png`明确并列C原生图、G生图概念、G整理后原生图。近眼保持单枚最深焦点，暖深棕上睑与眉分离；嘴用两枚相连暖棕像素及单侧提角，原鼻点与嘴分开；左鬓碎发合连续阶梯，未新增白眼/大睫毛。新增唯一色#9f5e40，实际变化18像素。

已实看这张三列图。修整版比初采样更有会意笑容，但17像素头无法完全复现raw，仍属用户待审候选。17:17不变、身体y21及以下与原图逐像素相等。脚本`repair_g_native.py`和`pixel_edits_G_refined.json`保存精确变更。

## 70×88：2倍工作稿对照实验

根审认为17px脸仍未达到审美要求。用户约束是头身约1:1，并未锁定17px头，因此追加一个密度实验：`sela_G_70x88_working_study.png`与`comparison_Gconcept_G2xstudy.png`。明确标识2x WORKING STUDY / NOT original native。

复核raw发现主要像素块约31px，但眼、眉、嘴包含半格或曲线细节，不能假设严格统一网格。先前整图缩到35×44，约31.94×31.98的采样步长与实际块边不一致，存在相位损失；强制八色映射进一步削弱眼嘴层次。新实验按raw头部实际边界x278..891、y127..650映射到70×88画布的x16..55/y8..41，采每格中心5×5范围的中值，保留raw原颜色并二值化alpha。身体为原Before最近邻2倍，y42以下逐像素相等，头34、身体34。

实际审看：眉眼方向和視线比17px版本显著可读，也更多保住概念脸；嘴的弧度仍被取样压平，浅笑没有raw完整。保留459种头部颜色，色板/密度与原版不同，不能称最终像素精灵或审美验收。未追加生成，未修改旧17px版本。
