# 双手木长棍关键姿态样板

无身份成年训练角色，原创Mod概念。准备 T0 → 后收蓄力 T1 → 向前短刺 T2 → 回稳 T3；T3完整复用T0。不是原版长柄技能、完整连续动画、换装系统或runtime资产。未修改其他动作或runtime。

## 原图与修正
内置imagegen共6张原图：独立透明木棍1张、身体初稿3张、蓄力局部修正2张。最终只有3个独立身体姿态。T1初稿握距过窄；第一次修正过宽；最终采用T1_fix2，淘汰图仍保存在raw中。每张prompt、原图SHA256与参考图SHA256见generation_provenance.json。没有用脚本重画身体。

## 尺度与固定装备
以最新interaction_v1/I0统一角色为基准，防御站姿主体935px为尺度约束。三个身体整画布统一最近邻从1254²放大至1478²，倍率1478/1254，然后平移至1536²画布、脚底y1380；T0实际主体935px。没有逐帧bbox缩放。短刺屈膝头顶降低不代表缩小。
木棍原图裁切后统一最近邻归一为1000px长、36px宽，仅此一次设备尺寸设定；各帧只刚体旋转/平移，不逐帧变长或镜像，纹理固定。两个局部握点x350、x750，恒定间隔400px，都在同一棍轴。手绘握持区域中选的锚点与刚体锚点差均小于0.4px，不能据此宣称亚像素原生绑定。

## 分层与实际观察
合成顺序：完整body_base → staff_rigid → rear_fingers_foreground → front_fingers_foreground。前景手套像素来自完整身体，mask只选择握拳区域；没有截掉手臂或修改身体来遮错。手腕/掌背保留在底层，握拳手指位于木棍前；关闭装备可见完整肩肘腕。两手均为上握，四个阶段始终只有同一木棍，没有单手剑或盾。
作者实际查看原图、中文检视图、跨动作尺度图与短刺大图：准备屈肘、后收蓄力与前伸短刺可读；两手连续连到肩肘，前膝弯曲与后腿延展有支撑。头巾、衣褶、鞋口和腰扣仍有生成漂移，前后手真实三维滚转与骨长没有量化，不能承诺无滑脚/无穿插的完整运动学。
