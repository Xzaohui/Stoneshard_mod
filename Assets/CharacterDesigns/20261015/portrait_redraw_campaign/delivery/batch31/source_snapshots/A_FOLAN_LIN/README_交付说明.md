## 解包复现与包校验

环境：Python 3.12、Pillow 12.3.0。在源包解压目录运行：

`python reproduce_candidates.py --output 一个尚不存在的新目录`

脚本读取同包 `portrait_redraw_campaign/` 下 raw 与完整回包，重新等比最近邻缩放、二值 alpha、量化并输出全部历史候选，逐像素、PNG字节和 SHA 与包内候选核对。A 包5张、B 包6张，已分别从实际 ZIP 解包复现通过。`portable_reproduction_verification.json` 保存每张结果。复现葛黎失败候选不代表视觉通过。

`python verify_source_package.py 源包.zip`

校验全部成员 CRC、SHA、字节数、精确成员列表及 `PACKAGE_SHA256SUMS.txt`。两包均小于18 MiB。包级清单保存原生产文件、独立 QA 和交付附件的来源与 SHA。

`build_delivery.py`、`package_sources.py`、`make_freeze_gate.py`、`source_validation.py`、`check_delivery.py` 为原仓库制作核验记录，依赖完整 campaign；解包后便携复现只需前述两条命令。不要在冻结目录运行会重写文件的原生产脚本。
