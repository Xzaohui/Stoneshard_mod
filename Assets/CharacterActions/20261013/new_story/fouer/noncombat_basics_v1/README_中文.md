本目录保存2张通过独审的独立全身关键姿态。内置imagegen首稿2次，修订0次。

- A1 坐稳将合板竖靠膝前：fouer_A1_tilt_closed_board_upright_on_lap_v1
- A2 稳板按回左袖原炭笔：fouer_A2_reseat_charcoal_in_left_cuff_v1

raw/含每一次生成原PNG和完整工具返回（image_url原图payload无截断）；prompts/含调用前逐字prompt和同字实参；sources/含本人母图raw/透明、现行卡/中文台词等原字节快照与SHA、规划证据及实际处理脚本；review/含真实浅深底、中文联合母图动作板、作者及独立QA。

alpha>8的生成像素保持原样；无量化、重绘、局部拼接、身体裁切或拉伸。母图和动作完整画布用同一0.47比例nearest排版。发色、衣色与未定造型均只为可逆美术提案，不改剧情源。苇珥英文旧串段不取，缶珥不添加实名/信仰领食门槛。

SOURCE_MANIFEST将旧动态独审快照明确标为captured_historical_report，仅核快照自身SHA；稳定独立plan_gate为实际生成门审依据。归档pixel skill已读，缺失executor-pixel引用未假称读取。
