## 复现与校验

Python 3.12、Pillow 12.3.0。在解包目录运行：

`python reproduce_candidates.py --output 一个尚不存在的新目录`

脚本读取同包 `portrait_redraw_campaign/` 内角色原始稿及完整回包，独立复现所有候选，逐像素与 PNG 字节 SHA 比对。A 包复现 6 张；B 包复现 4 张，包含维芮两张 held 历史候选。输出 `reproduction_report.json`；复现通过不代表 held 视觉通过。

`python verify_source_package.py 源包.zip`

脚本校验全部 ZIP CRC、成员精确清单、每个清单成员 SHA/CRC/大小与 `PACKAGE_SHA256SUMS.txt`。所有归档均已实际解包后运行复现。`portable_reproduction_verification.json` 保存该包的复现结果。

`build_delivery.py` 与 `package_sources.py` 是原仓库交付制作记录，依赖完整 campaign 目录及本批独立 QA；解包后的候选复现只需上面两条独立命令。原始生产脚本留作追溯，请勿在冻结目录直接运行会写文件的生产脚本。

## 质量边界

这是高分辨率生成原稿经整幅等比 NEAREST、alpha≥128 二值化、MAXCOVERAGE 至多 32 可见色与无抖动量化后的派生候选。32 色为临时技术上限，不是原生手工逐像素终稿，未集成游戏、未实机验证、未由用户最终批准。

- 尼芙：睫眼仍稍大，平行发束高光未完全合并。
- 欧岚：眉根仍有忧虑，顶部发量及条状高光偏多。
- 扎禾：浅眼白、平行发束及较多顶部透明留白仍在。现卡孤立“他”与同卡/现行台本“她”冲突已保留，按已审成年女性母版和当前台本处理；蓝染工作领按现卡，不改卡或旧图。
- 维芮：V2 原始图 x=1078、y=989–1053 连续 65 个 alpha≥128 像素触及右边界，真实发束缺轮廓。派生透明留边不能补回源缺失，源包 B 保留证据。
