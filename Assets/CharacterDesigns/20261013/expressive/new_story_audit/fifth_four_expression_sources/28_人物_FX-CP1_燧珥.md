# 人物_FX-CP1_燧珥

**工作**：营地边缘的逃散者，常在 `rumor_camp1` 一带。地域见 [[区域_R04_王廷关隘与边城]]。

**体貌与随身**：三十来岁的男人，衣领被扯开过，靴子只剩一只半；说话时背对着营地。

**口吻**：先说“我不是他们的人”，再回答问题；听到哨声就停。

**知情边界**：哨位草垫换班的时辰；哪条坡上不了。不说同伴是谁；不替营里任何人传话。

当前对白见 [[台本_FX_野外人物对白]]（中英对照，含关联台本 [[台本_N9_把证据摆上桌]] 的先做/后做与完成前后回访）；本卡不新增奖励、不替他人授权，拒绝有替代出口。
