# 伊沃地图新方法实验：未通过，停止生成

日期：2026-10-15 UTC。结论是一个有界工具能力测试失败，不是新的合格地图资产。没有游戏接入、运行验收、提交或推送。

## 结果

- 新稿比旧失败稿减少了脸部黑色纵柱，固定恢复后的有效身形20×34，已经不再强撑40高。
- 但模型没有保住指定35×44逻辑网格。请求的1120×1408参考比例，返回1070×1470；全画布对应单元是30.57×33.41，甚至不是方格。raw仍有21,968种可见RGB、256种alpha。
- 单元内部主色一致率：原生对照1.000；旧失败raw 0.644；本次0.707。10分位分别1.000、0.320、0.363。新稿有大方块外观，却不等于与指定格点对齐。
- 按固定格点机械派生得到35×44、有效20×34、15色、二值alpha文件，但这种恢复会改变原图像素簇，不能据此说原生网格生成成功。眼部仍偏纵条，嘴／下颌／领口仍拥挤；须同时看1x与原始图。
- 制作者等级：fail。独立QA已实际查看raw与1x/12x并确认fail：眼睛纵柱与眉／发暗块相连，下颌与领口粘连；固定众数是可复现重采样，不是原生设计恢复。独立测量报告由审查目录另行保存。本次只用一次初稿，未用修订。

## 与上轮的实质区别

上轮以高分辨率复杂图为对象，再裁切／最近邻拟合人物。本次以我们已有的真实35×44原创失败图放大32倍作为编辑对象，让imagegen重新组织粗格。原作木匠只是等尺度只读参照，不是改装成伊沃的底稿。新稿恢复时保留全画布，不裁切、不按包围盒拟合、不手工修脸。

这不是仅增加“pixel art”提示词的重复测试。真正低像素输入、全画布固定取格和网格一致性对照都有实测；结果仍然不足以证明工具能可靠制作指定35×44原生素材。

## 当前工具能力边界

已核查内置imagegen接口：没有精确原生尺寸、网格或palette参数。Pillow 12.3、NumPy、ImageMagick、GIMP可用；Aseprite/LibreSprite未安装。这些后处理工具能确定性取样／检查，不能替代缺失的像素美术安排。没有安装软件、付费、开账号或切换API。

当前证据仅支持“能做粗像素风格草图，能机械导出规定文件尺寸”；不支持“可稳定生成真正35×44原生地图像素簇”。在没有更可控的原生像素制作方案前，不建议继续用同类生图重试消耗额度。
