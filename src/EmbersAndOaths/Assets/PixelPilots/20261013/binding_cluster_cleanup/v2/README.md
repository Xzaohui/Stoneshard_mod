# 装订纸张色簇 v2：像素纹理重绘提案

一次针对 v1「过平、似规则倒角卡片」反馈的独立艺术修正。v1 和 native-study 成品没有改动。不是还原原纤维的无损变换，也不增加文字、符号或故事线索。

## 方法

- 从原 native-study 每层明暗的空间位置提取低频场，形成不规则、低对比纸渍色块。A 偏暖旧黄，B 偏浅奶白，保持两纸材质差异。
- 在原纹理的局部暗位置选取相距至少 15 像素的少量位置；每纸最多 18 处，绘制 6–7 像素短纤维簇，避免随机撒点。
- 边缘依据原纸暗颜料位置保留不均匀磨蚀，不画规则四边亮带或人工倒角。此色彩处理不改 alpha；合法纸边缺口全部保留。
- 共享不透明色共 11 色（每纸 5 色＋背景）。A/B 单像素色簇从 3428/3305 减为 3/6，而非追求归零。A/B RGB 改动为 10943/9189 像素；alpha、透明区 RGBA 改动为 0。

## 审图与限制

已实际查看 v2 4x sheet：不再是空白中心与规则亮边，纸面恢复稀疏纤维和不规则明暗，三孔与运动关系清楚。大块纸渍仍是简化、风格化处理，某些区域可能显得像斑驳色块；属于可比较的纹理重绘提案，不能凭技术测试称最终艺术达标。只做本次 v2 迭代，不继续无限平滑或加噪。

`comparison_source_v1_v2.png` 按左原源、中 v1、右 v2 排列，各为相同 2×2 四帧。另有最近邻 2x 对照、四帧、sheet、GIF、层/掩码、RGB 变化图。

## 验证与复现

`python build_cleanup.py` 只生成本目录；`python verify_cleanup.py` 独立回读导出。

- QA-readback.json：原源文件哈希、纸边/孔 alpha、四帧 A/B/背景归属、固定图层刚体合成、位移、10px 名义露边、GIF 无损回读、sheet 拼接均通过。
- QA-reproducibility.json：临时输出目录重跑后全部 20 个 PNG/GIF/manifest 文件逐字节一致。
- QA-v1-preserved.json：v1 已记录的 19 个图像/动画/脚本哈希全部仍匹配。
- manifest.json：完整源哈希、调色板、改动数和色簇统计。
