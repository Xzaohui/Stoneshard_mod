# 人物_ASH-S01-NPC_妮蔻

居住 [[聚落_ASH-S01_安息村]]；所属 [[聚落_ASH_寒凉盆地与护理村]]。身份、经历与口吻全部Mod原创。

**日常工作**：仍想住旧屋的患者。

**动机、缺点与可能转折**：怕承认需要帮忙就永远不能回家，所以最初拒任何陪护。限定代取让她可以承认部分需要而保旧钥；暂住营则仍保以后回村选择。她可继续不相信观察者，不必痊愈或迁出才算任务有好结局。

**生活台词**：「帮我拿锅，别顺手把门也替我关了。」

关联台本：[[台本_CS-ASH-01_安息村的旧钥匙]]；地域章 [[台本_CM-ASH_不是空床的村庄]]。

此人负责本地生活现场与有限观察，不替代台本原当事人的新同意、旧证据所有权和奖励。未亲历的案不能因同在本镇就知；须有具体公开事实或经本人允许的有限回执。已结案只有未来回应，不重开方法。

死亡/缺席时停本人新台词，基础安全可走现有固定痕和事前有限记录；不能让别的住户代该人和解、迁居或签未来劳动。上面的转折是可能弧线，具体发生须满足已执行方法和实际代价，并非走进聚落自动触发。
