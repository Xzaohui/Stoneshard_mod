# 白带回岸系缆桩：单候选结构研究

2026-10-13。仅拆旧04左侧一根桩，没有重画码头。内置 image_gen 一次生成，随后经用户授权的 Pillow/NumPy 缩放、固定色板及255处显式像素修整。旧图、台本、global/runtime均未修改，未安装软件、未push。

## 交付

- `concept_imagegen.png`：唯一新结构概念，完整工具提示词在 `prompt.txt` / `manifest.json`。实际概念仍有纹理和透视，不能直接称原生像素。
- `native_32x48.png`：透明32×48研究画布，可见17×42；13个不透明颜色，0/255二值alpha。
- `native_8x.png`：纯最近邻8倍；`view_1x_*` / `view_8x_*`用于中性、深、浅背景查看。
- `native_before_edits.png`：缩放减色后、像素修整前，保留以证明并非直接缩图交付。
- `old_new_reference_comparison.png`：旧04裁图与新稿、原桶、Jurg。旧图为适配裁图；新稿/桶/Jurg严格同为8倍。
- `material_camera_review.png`：原书架及Frid环境补充对照，截图不用于尺寸推断。
- `edits.json`：255处坐标、色板索引和原因；`reproduce.py`从概念复现native；`make_review.py`复现对照与哈希manifest。

运行：在任何工作目录以Python运行本目录`reproduce.py`，再运行`make_review.py`。需现有Pillow/NumPy，无下载或新安装。manifest保存所有输入与输出SHA；其本身不自哈希。AI概念不能按同提示词保证逐字节重生，已保存原输出以复现后处理。

## 来源与比例界限

已实际查看旧04、原Barrel_0、Bookshelf_0及Frid_environ；读取原batch01提示词、根manifest、BRY-X11空间及CS-BRY-11台本。旧04 SHA与旧manifest一致。具体来源URL、文件SHA与版本局限见manifest。

同材质与相机参照，不是同物原版匹配。没有找到原版同类桩单精灵，故不编原资源名、origin、深度或engine尺寸。官方Wiki桶/书架为2021历史原画，未与本地0.9.4.25逐资源核验；原桶可见24×25不是所有道具规格。Frid环境只校气质，相机缩放未知。

选择32×48而非机械套NPC可见34px：这是稍高的回岸地标试验，给白带、木质间隔、绳结、悬绳负空间及水痕分开留像素。42px可见桩高超过Jurg可见34px，尚需在真实码头视野与遮挡中核验，不可声明正式尺寸。若使用场景不需高地标，下一步应先调整放置比例再定稿。

## 实际视觉QA

已看1x及8x，中性、深背景，并查看旧新同倍率参照；色数/alpha仅技术检查。

- 白带连续浅核心与右侧阴影分开，1x能先读到白带；不画字/箭头/产权标志。
- 绳结在左前凸出，带暗交叉和浅结头；悬绳与桩身间有1px透明负空间。1x能辨识系绳/结头存在，但绳结具体打结法不作工程认证。
- 白带下留木材间隔再到绳圈，没有合并成第二条白带。底部为深灰绿水痕簇，没有密集藤壶。
- 顶面是窄扁椭圆、左亮右暗保圆柱体积，木纹是少量短簇。降低了旧稿细密年轮/木纹；仍有细长柱体倾向，不以“通过”代替审美终审。
- 深背景下右轮廓自然更弱，白带和绳结仍可辨；实地图层/投影/邻水背景未验证。

结论：可交独立审阅的单件研究候选，未获用户美术验收，也未导入游戏。碰撞、锚点、深度、交互范围和与场景的比例仍待核。

## 叙事界限

白带保留清楚的“回岸标记”视觉特征；单桩不画道路，真实回岸路线由后续场景布置保证。它不是所有权、自由出入许可、自动出航或任务完成证明。没有合入另一个载重刻度桩；确认载重、回岸与各人授权仍是独立行为。
