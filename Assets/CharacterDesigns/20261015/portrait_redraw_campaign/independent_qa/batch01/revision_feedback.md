# 第一组独立集中修订反馈

2026-10-15 UTC。仅在首次实际查看 raw 与 1x/8x 派生后给出。每张最多一次必要生图修订，未要求以次数填满预算。

## Mia v1 → 唯一修订

身份、低辫、暗青/米白衣色可辨，成年鼻翼和颧骨成立。当前长颈露出、偏大亮眼白、眼尾上挑长线与细平行发带需要收束。集中要求：缩掉下颌至胸口过多长颈，只保窄领；压低上睑、稍缩眼裂、暗米灰眼白、去猫眼长尾；顶发和低辫合宽整束。保较长窄脸、苍白肤色、自然疲惫与不对称紧嘴，避免复制Mara圆眼红润脸或Leiya宽脸，不用密皱纹强行增龄。反馈已发送生产者。

## NELL v1 → 唯一修订

长鼻/颧骨及深蓝米白衣色已成立，但与Mia v1/Mara的斜前发、上挑眼尾和担忧眉近似，底部过长颈与披肩占比也偏大。集中要求：紧脸缩颈、窄米领深蓝；开放额头、前发后梳并入低盘发、去脸旁长卷、合4–6发块；更平直细眉、压上睑、减暗米灰眼白、短薄闭嘴，保40多岁书记克制审慎和眼下红痕。保长脸长鼻，不靠密皱纹/灰发强行变老。反馈已发送生产者。

## ENA v1 → 唯一修订

米头巾、棕衣和成年忧虑成立，脸型仍接近Mia的统一模板；大亮眼白、上抬眉弓和长颈让其偏哭诉。集中要求缩颈紧脸，头巾压为3–4整块并保系结；脸稍宽、鼻翼钝宽，上睑压低、小暗米灰眼白、嘴平而坚定。保务实忧虑，不增密皱纹。

## NARA v1 → 唯一修订

短须锈色工装身份成立，面部仍接近Tore窄脸、发梢偏刺猬尖。集中要求宽面中/下颌、钝宽鼻翼，乱短发收4–5大参差块、短须合整块；缩长颈只保窄锈领和一点工装带，保侧看出口的戒备，不画凶恶。

## SEL v1 → 唯一修订

灰短须和锈红/炭围裙身份鲜明，50岁读感成立；头发细白条、须内棋盘细碎与衣领占幅是主要问题。集中要求灰发灰须合大连贯亮暗块、去碎白条，压上睑缩暗眼白并略松眉心；紧脸缩颈，保窄锈红/炭围裙边。保厚眉厚脸和疲惫盘算，不转美型或增大年龄。
