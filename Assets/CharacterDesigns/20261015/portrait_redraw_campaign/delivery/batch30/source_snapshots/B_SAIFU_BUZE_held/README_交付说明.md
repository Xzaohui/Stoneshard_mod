## 复现与校验

环境：Python3.12、Pillow12.3.0。解包后运行：

`python reproduce_candidates.py --output 一个尚不存在的新目录`

脚本从同包`portrait_redraw_campaign/`人物目录读取完整raw和回包，逐一独立复现所有历史候选，核对像素与PNG字节。源包A复现7张（提奥3、凯诺4）；源包B复现5张（赛芙2、布泽3）。输出`reproduction_report.json`。held技术复现通过不构成视觉通过。

`python verify_source_package.py 源包.zip`

逐一校验全ZIP CRC、精确成员清单、逐成员SHA/CRC/大小及`PACKAGE_SHA256SUMS.txt`。两个ZIP均实际解包再运行复现；12份历史候选与冻结原件逐字节一致。各包`portable_reproduction_verification.json`保留实际复现结果。

`build_delivery.py`、`package_sources.py`、`make_freeze_gate.py`、`source_validation.py`、`check_delivery.py`为原仓库制作与检查记录，依赖完整campaign和独立QA；解包复现只需前述两条命令。原生产脚本供追溯，不要在冻结目录直接运行会写文件的生产脚本。
