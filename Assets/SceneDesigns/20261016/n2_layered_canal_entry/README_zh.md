## 六层交付

全部为 **1536×1024 RGBA PNG**，左上角(0,0)对齐；交付层 alpha 只有0/255。

1. `layers/00_bank_cutaway.png`：完整石砌主体、岸墙拱口、通道暗部与台阶、前室地面、右侧抬高干台。正面墙体省略以展示内部。
2. `layers/01_roof.png`：独立低瓦顶与木檐，整层可隐藏。
3. `layers/02_maintenance_door.png`：独立敞开的维护门，安装在拱口右缘，不封死通道。
4. `layers/03_maintenance_ladder.png`：独立靠左墙检修梯。
5. `layers/04_bedroll.png`：独立空铺盖，位于右侧干台。

实际叠合顺序：00主体 → 02维护门 → 03检修梯 → 04铺盖 → 05水罐 → 01屋顶。
揭顶仅隐藏01；隐藏维护门仅去掉02，其余图层和位置完全不变。没有重生成整景来冒充分层。

## 题材与边界

- N2-S03：事故后未归营工人藏身旧渠侧间；这里仅画环境，不加入人物或决定其去向。
- D02：干渠路线、可辨认维护门、活人侧间与墓龛战区分隔；检修通路保留，不把生活干台画成水槽。
- R01：盐灰石、褐木、潮湿砖、低处旧泥线；参考旧入口及此前游戏素材的材料与可读形态。
- 无尸体、遗骨、棺材、墓铭、战利品、结案证据、姓名或救援成功标识。
- 这是将旧小型门楼发展成可观察前室的美术提案，位置和建筑尺度未作为正式拓扑确认。原N2入口door_cell[42,14]、return_cell[42,16]及侧间道具节点仅作只读来源。
- 画中检修梯、维护门和铺具不证明攀爬、开门、救援、状态写入或交互功能已实现。

## 绘制与核对

内置 image_gen 逐层绘制六张初稿；屋顶因初稿后墙顶柱露出，做一次必要修订，采用v2。共七张原稿全部保留，五个非屋顶图层均使用初稿。

后期仅使用 ImageMagick 的选区裁切、alpha 50%阈值整理、最近邻缩放、整数平移和实际 source-over 叠合。屋顶采用非等比纵向压缩并上移，铺盖也按干台投影作非等比尺寸调整，完整数值见 `TRANSFORMS.txt`。未使用Python图像编辑、透视扭曲、程序绘画或算法生成素材。

已目视检查揭顶、盖顶、分层、通道门梯、干台与屋顶接缝：后柱和横梁不再越过瓦顶；左右前侧檐口与石墙相接；铺盖和水罐落在干台，中央通道保留；隐藏道具后底图连续。

`raw/`、`prompts/`、`sources/`分别保留原稿、完整提示词和只读来源。`generation_manifest.json`记录来源对应，`art_review.json`记录本次美术检查，`SHA256SUMS.txt`记录文件哈希。`previews/process_review/`为过程检查，非最终推荐图。

本目录仅是高分辨率分层概念候选；未宣称原生26px素材、限定色板、碰撞、生产锚点、动画或运行效果通过。未改代码、接入、校验器、台本或游戏包，未push。
