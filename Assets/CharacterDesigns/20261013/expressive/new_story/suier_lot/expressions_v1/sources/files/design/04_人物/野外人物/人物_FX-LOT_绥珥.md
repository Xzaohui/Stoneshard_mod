# 人物_FX-LOT_绥珥

**工作**：裁缝宅子亲属，常在 `rumor_homesteadLooted1` 一带。地域见 [[区域_R03_曼恩边地]]。

**体貌与随身**：四十来岁的妇人，围巾结得紧，手里攥着半截布尺；说话时先看院子里的染缸。

**口吻**：先解释自己为什么来，再谈东西；被怀疑就沉默。

**知情边界**：哪几匹布是自家的；抢东西的人往哪边走的。不认领别人家的东西；不替宅子新主人说话。

当前对白见 [[台本_FX_野外人物对白]]（中英对照，含关联台本 [[台本_SQ03_没有王旗的面包]] 的先做/后做与完成前后回访）；本卡不新增奖励、不替他人授权，拒绝有替代出口。
