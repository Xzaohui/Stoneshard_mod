# 齐勒原创短步关键帧 v1

查看`chiler_walk_keyframes_review.png`：W0静站支撑、W1抬脚摆步、W2短步接触。W0沿用源图，W1/W2为内置imagegen各自编辑的新姿态。逐帧透明图在frames；原始输出originals；提示词与manifest保留。

`chiler_short_step_preview_once.gif`是650/650/1500ms的单次关键帧检查，无插值，没有用平移同图冒充摆腿。尚无后续收步和左右腿交替，不称完整循环，也不强行首尾复位。

统一1536²逻辑画布；地面基准y1380和站位x768为工作约定。原始生图1254²按整画布最近邻统一，不按逐帧人体bbox缩放。W1检测到支撑脚平移漂移，归一后全图平移(-78,-16)恢复屏左脚落地位置；这一步仅对齐、不制造关节动作，未对齐稿也保留。W2前足接触在y1375，允许透视约5px区别，不为贴线扭腿。

这三阶段属Mod原创步态演绎，不是从官方Dash GIF取得的原版关节帧。木棒始终为向下的指示棒，同原图屏左手持握，不赋予战斗用途。解剖左右未经骨骼证据确认；当前仅锁同一图像侧手。

作者初审：抬脚与落脚现在可辨；头脸仍有少量生图重绘变化，人物脸宽/纹理与原图并非逐像素锁定。需独审决定是否可作概念关键帧，不能仅凭画布或脚点相同判通过。

engine_origin、collision、native_fps/directions均未知；runtime_verified=false，换装兼容未测。附着点仅手工粗估检查坐标，实际导入前必须精确重测。
