## 解包复现与包校验

环境：Python 3.12、Pillow 12.3.0。在源包解压目录运行：

`python reproduce_candidates.py --output 一个尚不存在的新目录`

脚本读取同包 `portrait_redraw_campaign/` 下 raw 和完整回包，重新等比缩放、二值 alpha、量化并输出全部历史候选，逐像素、PNG字节和 SHA 与包内候选核对。A 包6张、B 包5张，已分别从实际 ZIP 解包复现通过。`portable_reproduction_verification.json` 保存每张结果。复现卡蕾失败候选不代表视觉通过。

`python verify_source_package.py 源包.zip`

校验全部成员 CRC、SHA、字节数、精确成员列表以及 `PACKAGE_SHA256SUMS.txt`。两包均小于18 MiB。包级清单保存原生产文件、独立 QA 和交付附件的来源与 SHA。

`build_delivery.py`、`package_sources.py`、`make_freeze_gate.py`、`source_validation.py`、`check_delivery.py` 为原仓库制作与核验记录，依赖完整 campaign；解包后的便携复现只需前述两条命令。不要直接在冻结目录运行会重写文件的原生产脚本。

## 质量边界

高分辨率生成原稿经整画布等比 NEAREST、alpha≥128 二值化、MAXCOVERAGE 至多32可见色及无抖动量化得到派生候选。三张入选稿将完整原画布等比放入72×98后居中到74×100；未裁切、补画、改脸或扩边。32色是临时技术上限，不是原生手工逐像素终稿；未集成游戏、未实机验证、未由用户最终批准。
