# Batch67 · 三个人物剧情动作概念

- 玛莉丝：捏住批次签一角 → 撕开短口 → 停住，纸角仍相连。
- 罗温：地图正面 → 同一张纸翻转中 → 空白背面平放。
- 米蕾：持旧席板 → 俯身放下 → 席板置于椅面、双手离开。

每板三关键帧，实际均为1536×1024。来源、守卫、完整提示词、输入输出 SHA-256 见 manifest.json；作者检查及具体局限见 QA.json。采用内置 imagegen，第三方 pixel-asset-master 只读指导，未执行其脚本。旧参考、原生成文件均保留。

本批只表达台本中的有限动作，不决定退货、地址交易、死亡、返回、泊位、租约或等待的结局。人物在场/存活/意愿及各场知识条件仍须由实际逻辑决定。构图和椅子等具体造型是美术提案；色数、像素栅格、锚点、逐帧清理和引擎运行未验收，不是可循环动画或最终游戏精灵。
