## 六个独立图层

全部为 1536×1024、8-bit RGBA PNG，同一画布和原点，放置时无需再次居中。文件编号是资产分类，不是叠放顺序。

1. `layers/01_ground.png`：室内地面及静院公共窗前铺地
2. `layers/02_structure.png`：完整四面无顶壳，左前交样窗、右前返院门、窗台与窗扇
3. `layers/03_roof.png`：可整体隐藏的独立瓦顶
4. `layers/04_furniture.png`：空验样台和关闭限权柜
5. `layers/05_contact_items.png`：柜顶限定联系人筹与关闭皮套，无可读身份信息
6. `layers/06_removable_sample.png`：独立布样及可拆夹边，位于公共窗台

揭顶叠放顺序：01 → 02 → 04 → 05 → 06。盖顶在其上添加 03。

## 场景意思与边界

- 公共交样窗面向静院，窗外即可核看固定样。布样只表达工艺差异，不证明公开姓名、地址、归责或结案。
- 技术样与联络资料分开：布样在公共窗，有限联络物在室内另一侧的关闭柜区域。不画名单、姓名、地址、广告署名或已授权结果。
- 右前返院门无锁、无遮拦；该门表达本间独立返回 ALD-D01 街口的意图，不经卧房或危险工区。
- 台架与柜体脚已移至地面内，屋顶覆盖内室并与墙顶对齐；揭顶后四面壳仍连续，不依靠屋顶补洞。
- 画面为分层绘画候选，不是原生像素素材，不是已导入房间。碰撞、瓦片比例、游戏交互、运行效果和用户最终认可均未核验。

## 文件留存

- `raw/`：六层初稿，以及无顶壳唯一一次必要修订，共七张原始生成图

- `layer_properties.txt`、`SHA256SUMS.txt`：文件属性与候选哈希
