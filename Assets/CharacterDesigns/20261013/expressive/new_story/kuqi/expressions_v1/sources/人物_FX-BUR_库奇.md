# 人物_FX-BUR_库奇

**工作**：蛛洞拾荒人，常在 `rumor_crawlerBurrow1` 一带。地域见 [[区域_R01_布林外港与旧渠]]。

**体貌与随身**：瘦小的中年人，背着缠满布条的钩杆，腰上挂一圈旧绳；手指关节全是旧咬痕。

**口吻**：快、碎、爱插笑话；一提到洞里就立刻改口认真。

**知情边界**：洞口什么时候起风；哪种丝能卖钱，哪种一碰就断。不替人进洞取东西；不知道洞里到底有几窝。

当前对白见 [[台本_FX_野外人物对白]]（中英对照，含关联台本 [[台本_N12_失踪者仍有名字]] 的先做/后做与完成前后回访）；本卡不新增奖励、不替他人授权，拒绝有替代出口。
