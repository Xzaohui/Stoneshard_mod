# 野外内容规则一致性审计

按 S62 与各台本顶部规则，对新阶段四个登记文件与六张地点卡做一致性重算：无奖励/无前置/无重复任务字段、拒绝与缺席出口、知情边界、中英对齐、服务不新增、44 地点落点。本页只验规则与结构，不评文学质量、不证明运行。

## 口径

- “无奖励字段”指四个登记文件里没有 reward/requires/repeatable/cooldown/price 等键；野外内容只给信息与口信。
- “缺席替代”要求每人有 proxy 节点与 proxy 台词；“拒绝出口”要求每人有拒绝句且条件流含 refused 状态。
- “服务不新增”逐卡核对服务栏必须声明无固定服务或等义措辞。

## 边界

- 重算只覆盖登记文件与地点卡；运行表现、数值与生成点不在本审计范围（见[[特殊地点阶段制作与校准规程]]）。
- 审计通过不等于内容可用；文学、节奏与实机表现仍需人工与运行验证。
