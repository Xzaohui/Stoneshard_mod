## 使用与状态

- 4 张独立 PNG 是冻结 candidate，74×100、RGBA、二值 alpha，逐字节复制选稿。可见 RGB 色数依次 30、31、32、32；≤32 色只是本批临时上限。
- 中文手机总览为每人 1× 原尺寸＋4× 最近邻。只排版，没有补画、重绘或改色；1×/4×区域均逐像素核对。
- 本批使用内置生图完成实质重绘；高分辨率 raw 经整幅最近邻缩小、alpha 阈值 128、无抖动量化派生。托曼/塞娜使用 MEDIANCUT；莉德/莫伦使用 MAXCOVERAGE。
- 不是原生手工逐像素终稿；尚未接入游戏、未做实机验证，也不代表用户已认可本批新稿。
- 托曼：兜帽使脸略小、灰须细纹；塞娜：底部围巾仍约 16 像素；莉德：眼白略亮、发髻仍偏大、脸放大幅度有限；莫伦：眼白略亮、须发细纹和围巾面积。以上为独立 QA 非阻断余项，完整结论见 QA_REPORT.md。

## 源包

两个文件是各自可解压的普通 ZIP，不是分卷压缩包：
1. batch02_source_A_TOMAN_SENA.zip：托曼、塞娜全部制作过程与来源。
2. batch02_source_B_LYD_MORLEN.zip：莉德、莫伦全部制作过程与来源。

每包共有：全组独立 QA、中文总览与 4 张选稿、交付清单、来源排除清单、校验和、核验脚本，以及便携复现脚本。每个角色保留全部 raw、提示词、完整工具返回、历版候选、导出脚本、预览、来源人物卡/身份图/风格图、作者 QA 与原始 manifest。

商业原生参考像素不随包分发；其原始路径与 SHA 保留在来源清单和 DELIVERY_EXCLUSIONS.json。自有生成身份/风格参考保留。生产 SHA256SUMS 原样留档，可能引用主动排除的商业图，不能当作实际包内容清单；实际封包清单为 package_inventory.json / PACKAGE_SHA256SUMS.txt。

两个包可解压到同一空目录，公共文件字节完全一致。历史作者与审查脚本原样保留，部分依赖完整原仓库路径，不能直接据此断言解压即能跑完整仓库审计。

## 复现与核验

- python3 verify_source_package.py <源包.zip>：校验全部 ZIP CRC 与逐项 SHA-256。
- 安装 Pillow 后，在任一解压目录运行 python3 reproduce_candidates.py --output <新的空目录路径>：只读取包内 raw/tool_returns/candidates，按对应量化算法复现该包角色的全部候选，在单独输出目录逐像素与 PNG 字节比对。不会改动冻结文件。封包测试使用 Pillow 12.3.0；其他版本输出字节可能不同。
- 全组六张候选已独立复现；所选四张 SHA 与 selection.json、作者 manifest 和交付 PNG 一致。
- 包内工具返回保留完整 data URL，仅用于审计与复现；不需要登录、服务密钥或调用外部生成服务。
