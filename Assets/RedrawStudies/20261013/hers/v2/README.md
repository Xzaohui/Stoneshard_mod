# 赫斯 v2：独立QA后的限定像素退修

旧v1完整保留，本次不再生成多向或动作。此修订是在父任务明确的本地像素修整授权下，对已生成新结构画稿的native派生物进行定点修整；没有重新调用生图工具，也没有把旧124缩小当作新结果。

## 具体变化

1. 将西装式V翻领尖片合并为普通炭灰羊毛闭合前襟；骨色亚麻仅保留短领口，不加胸徽或新服装道具。
2. 灰发改为少数连片灰褐簇，额/颊减少零碎高光，保留两眼/鼻桥、退发线与淡须；不更换脸为任何原版NPC。
3. 账簿从v1不规则9×6棕块重绘为独立12×8闭合静物：棕封面、左侧直深书脊、浅页边。12×8只是小幅可读性预算试验，非engine标准；无字、章、签名或新证据，没有放进赫斯手中或叙事移动。
