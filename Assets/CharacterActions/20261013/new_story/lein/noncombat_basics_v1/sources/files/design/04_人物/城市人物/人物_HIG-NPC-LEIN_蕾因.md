# 人物_HIG-NPC-LEIN_蕾因

**稳定ID**：HIG-NPC-LEIN

**身份**：接过观景客约的成年向导

**所求**：把客人真带回，也怕退订失旅费和信誉。

**所怕**：停牌让自己过往夸大的广告被认出，觉得自己再无工作。

**口吻**：先谈客人已付的路费，受质疑会承认写过无需等待。

**跨案弧线**：01须撤免检通行说法并承认退款/改约，主章可改做真实外道引路；03少展示便宜少收入，但不把原承诺失约推给维护者。
