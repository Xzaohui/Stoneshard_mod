# N2 原生场景 HD2D 适配 v1

2026-10-14，随 0.3.3 开发观察包接入现有安装。美术来源为已冻结的 R01-camp-canal-v2；本目录为新派生版本，不改原批次或其交付包。

包含雇工棚、塌堤绞盘、旧渠侧间各四层，共 12 张原生 1040×780 场景层，另复用空棺、轴座与三张建筑外观精灵。26×26 可走格直接读取 N2Quest.cs，PNG 透明度不生成碰撞。建筑外观显示在观察卡上，尚未作为可进入的建筑实体落位。

F6 开启观察，F7 揭雾，F9 原生碰撞格，F10 切换 HD2D；F11 按岸院、钟屋、暗渠、雇工棚、塌堤、侧间巡览，Shift+F11 返回首次出发位置。F8 的世界地图测试传送保留。

复现：先运行 tools/Export-Hd2dNativeN2.py，再运行 tools/Validate-Hd2dNativeN2.py，随后 tools/Build-Mod.ps1。工程显式嵌入本目录 PNG，运行不读取外部图片路径。构建中的开发检查读回纹理字节、原点，并比较实际序列化的原生碰撞格。

本轮已进入上述六个场景，验证 F10 对比、F9 格网、雇工棚相邻格移动、N2 返回原坐标和关闭揭雾。证据：artifacts/dev-runtime-20261014.json 与 artifacts/runtime-20261014/。完整任务分支、每个门、道具点击、全部存读档与建筑落位仍待后续验收。

本目录不计入新原创母图或新增请求视图数量，不改变主素材库 193/745 的制作进度。NPC 外观、对白、任务状态与奖励实现继续由原模块负责。
