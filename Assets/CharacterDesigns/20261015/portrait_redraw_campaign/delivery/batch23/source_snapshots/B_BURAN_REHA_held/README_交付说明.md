## 复现与校验

Python 3.12、Pillow 12.3.0。在解包目录运行：

`python reproduce_candidates.py --output 一个尚不存在的新目录`

脚本读取同包 `portrait_redraw_campaign/` 内人物完整 raw 与回包，独立复现所有历史候选，逐像素和 PNG 字节 SHA 比对。A 包复现6张（桑勒2张、温诺4张），B 包复现4张（布岚2张、雷哈2张）。输出 `reproduction_report.json`；复现通过不代表雷哈视觉通过。

`python verify_source_package.py 源包.zip`

脚本校验全部 ZIP CRC、成员精确清单、每个清单成员 SHA/CRC/大小与 `PACKAGE_SHA256SUMS.txt`。所有归档均已实际解包后运行复现，10张历史候选字节完全相同。`portable_reproduction_verification.json` 保存该包复现结果。

`build_delivery.py`、`package_sources.py`、`make_freeze_gate.py`、`source_validation.py`、`check_delivery.py` 是原仓库交付制作/核验记录，依赖完整 campaign 和本批独立 QA；解包复现只需前述两条独立命令。原始生产脚本留作追溯，请勿在冻结目录直接运行会写文件的生产脚本。

## 质量边界

这是高分辨率生成原稿经整幅等比 NEAREST、alpha≥128 二值化、MAXCOVERAGE 至多32可见色和无抖动量化后的派生候选。32色为临时技术上限，不是原生手工逐像素终稿，未集成游戏、未实机验证、未由用户最终批准。

- 桑勒：V2 full；约40岁，松面笑纹、棕发薄须、梅帽兑筹缝记、梅外/黄褐里成立，警觉侧目与克制半笑可辨。完整帽发耳、短颈和大脸改善；仍有亮眼白、略抬内眉、偏大帽发占幅与细纹。
- 温诺：V2 containment；约50岁、净面、沙棕夹灰发、蓝/米白衣色与湿布披肩边。完整 raw 等比放入70×96框后居中，未裁切、补画或修形；原始右发尖真实余量仅5px高分辨率像素，窄。containment增加派生画布余量，不等于生成扩边。眼白仍亮、发纹和皱纹偏碎；其他三份技术候选仅留作历史。
- 布岚：V2 inset；40多岁炭份保管人，厚实脸宽鼻、灰棕短须、暗帽/棕厚工装和赭内衫。完整帽发耳、短颈、大脸与连通发须块改善；眼白偏亮、内眉微忧，稀疏眉辨识仍有限。原始右10px/底11px高分辨率余量窄。
- 雷哈：V2 raw 在1078×1459画布最右列 x=1077、y=531–546 连续16个 alpha≥128 像素（最高254），右发卷真实平截。inset后透明留边不能补回源缺失；V1也未获批准，不回选。源包 B 保存全部失败历史；两包独立 QA 保留裁边证据图与逐像素记录。
