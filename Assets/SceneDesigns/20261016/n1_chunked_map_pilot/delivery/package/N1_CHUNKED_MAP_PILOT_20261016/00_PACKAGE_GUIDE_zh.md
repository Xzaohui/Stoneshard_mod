# N1 独立地块试拼：精简美术交付包

本包为2026-10-16冻结的2×2地块视觉候选，只含美术和布局数据。不是完整N1地图，也没有Godot脚本、碰撞、导航、动画或游戏运行验收。

## 使用入口

- 最终贴图：chunks/下4张 *_core.png，均832×832。
- 按chunk_layout.json的world_origin_px放置：NW(0,0)、NE(832,0)、SW(0,832)、SE(832,832)。
- 最终贴图全幅显示，裁切为(0,0,832,832)。接缝已烘入最终core，不得再次叠加seam。
- 1254×1254是四块的原始生成尺寸；1040×1040是规范后的含halo生产源图；生产源图四边各104px余量，取(104,104,832,832)得到基础core。该源裁切不能再用于最终832贴图。
- 整体图是四块真实拼接，已逐像素核验；没有另生一张全景作为展示图。

## 本精简包包含与省略

包含4张最终core、布局、作者README、变换记录、生成来源记录、完整提示词、台本与拓扑依据、整体/边界/接缝板及7张原尺寸接缝局部。

为控制体积，省略raw/、normalized/、基础core、生产用seam图片、共享参考带和历史失败预览；这些仍保留在原制作目录。作者README、布局及来源记录中的上述路径是完整制作链索引，并不表示相应生产源图已包含在本精简包。生产链中的seam仅解释来源，运行时不再加载。

SHA256SUMS.txt是完整制作目录冻结指纹，包含本包省略项，不能在精简包根目录直接全量验收。PACKAGE_SHA256SUMS.txt仅覆盖本包实际文件（自身除外）；PACKAGE_SOURCE_MANIFEST.json记录每个原文件的来源路径和SHA256。所有被选文件按原字节复制，没有改写图片或布局。

## 独立视觉复核与范围

本候选可展示；道路、岸线和南堤未见阻止展示的硬接缝。仍有中央白色水纹偏强、桥下双列流纹重复及局部颗粒密度差异。26px逻辑格和35×44人物参照只用线框示意，未叠真实角色或做可行走验证。

四块服务于当前固定邻接关系，依赖专用接缝补绘，不是可任意重排的通用瓦片。建筑、钟架、人物仍需独立制作/接入。此包不能表述为已经实现Godot或原生游戏地图。
