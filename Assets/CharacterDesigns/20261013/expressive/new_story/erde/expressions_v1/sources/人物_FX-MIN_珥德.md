# 人物_FX-MIN_珥德

**工作**：矿洞捡拾者，常在 `rumor_mine1` 一带。地域见 [[区域_R06_无名修院山地]]。

**体貌与随身**：五十来岁的男人，膝盖绑着皮垫，背篓里全是矿车残件；说话时先敲一敲支撑木。

**口吻**：慢、稳，句子里全是木头与石头的名字。

**知情边界**：哪段支撑木还顶得住；矿车轨哪一节陷了。不替矿主认领工具；不下最深那段。

当前对白见 [[台本_FX_野外人物对白]]（中英对照，含关联台本 [[台本_DT15_封存之后的巡查]] 的先做/后做与完成前后回访）；本卡不新增奖励、不替他人授权，拒绝有替代出口。
