# 人物_DEN-NPC-BEVI_蓓薇

**稳定ID**：DEN-NPC-BEVI

**工作**：瑟芬的妹妹与第三户回迁者

**所求**：保留离村照料母亲的经历和自己旧居请求，不被哥哥抹成没回来过。

**所怕**：哥哥以照顾留村者为由永远替她决定住处，或自己拿旧门痕去逼别人搬出。

**口吻**：说那年从哪扇门带母亲走；她可以接受这晚先住驿站，也仍要漏名得到更正。

**可能弧线**：先住别处不放弃旧请求，回住也不向哥哥补忠诚；修屋自选有限份，不靠同意劳动才恢复名字。
