# 人物_FX-CMP_珥泰

**工作**：兵营清点人，常在 `rumor_camp4` 一带。地域见 [[区域_R04_王廷关隘与边城]]。

**体貌与随身**：三十来岁的男人，穿着不合身的旧军衣，手里一块点名的木板；说话时用笔杆敲板。

**口吻**：照单念名字的腔调；被问军务就摇头。

**知情边界**：床架被拆走几副；军旗杆座还在哪。不评军务与调令；不认领遗落装备。

当前对白见 [[台本_FX_野外人物对白]]（中英对照，含关联台本 [[台本_SQ02_被征用的冬粮]] 的先做/后做与完成前后回访）；本卡不新增奖励、不替他人授权，拒绝有替代出口。
