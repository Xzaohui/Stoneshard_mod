# 人物_ASH-NPC-SUNE_苏奈

**稳定ID**：ASH-NPC-SUNE

**身份**：本批自愿观察记录员

**所求**：拿到可用记录，保住自己的有限差事。

**所怕**：停止观察后被说毫无价值，自己也失下次雇费。

**口吻**：先问愿否再写数字；压力下曾把普通物资说成观察名额。

**跨案弧线**：03须实际取消物资与观察捆绑，或停止本批；肯纠正不自动取得患者谅解，过去诱导许可不倒写成充分自愿，记录源和拒绝都留史。
