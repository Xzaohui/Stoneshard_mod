# 齐勒刚性位移表现研究

沿用已审原稿，共1个独立主体；4张PNG只是同一主体平移后的检视位置，GIF为13次整数像素位置采样，不计新增绘制。无人物镜像、腿部重绘或武器替换。

参考：2020-03-15官方Athletics Devlog中Dash示例可见紧凑主体位移和拖尾（本项目ReferenceAudit/20261013/actions/REFERENCE_AUDIT.md）。这里只借鉴“主体位置变化”表现，未复制第三方图像，也未给齐勒添加战斗冲刺技能；本样例不含拖尾。

1536²为研究画布，root工作点从(588,1380)到(876,1380)，y固定。GIF中移动采样40ms，首尾400/650ms，单次播放无回跳；这些都是检视设定，不是游戏速度。足底随主体在地面上平移，明确存在滑移，这是刚性表现演示，不能叫完整交替步行、无滑步或物理接触验收。

此前walk_cycle_v2/v3_rig/v4_guided均保留研究。两轮局部生成仍未解决K1支撑重心和远腿髋膝踝可读性，独审建议停止扩展；没有完成完整循环。

换装兼容、原生origin、碰撞、事件、方向、游戏内播放均未验收。
