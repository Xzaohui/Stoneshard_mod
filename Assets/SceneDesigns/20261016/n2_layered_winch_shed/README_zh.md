4. `layers/04_tool_stub.png`：薄纸工具借用存根，平面小印跨纸折；位于左滑木下，边角和部分印迹可见，可独立移出查看。

叠放顺序：主体 → 存根 → 绞盘残件 → 刻刀 → 屋顶。屋顶开关不改变其他层。
