# 0.3.14 开发观察模式

用于当前 Stoneshard 0.9.4.25 modbranch / MSL 0.13.2.0 安装。早期运行证据见 `artifacts/dev-runtime-20261013.json`，0.3.6 场景抽查见 `research/art-runtime-todo-20261015.md`；离线校验不代表实机通过。

加载角色后按 F6 开启，默认关闭。快捷键已核对本地原事件为空；F8沿用现有测试传送。

| 按键 | 功能 |
| --- | --- |
| F5 | 显示/隐藏观察面板，不关闭观察模式 |
| F6 | 开启/关闭开发观察模式；关闭时恢复原雾层显示 |
| F7 | 临时显示被雾层遮住的画面；再次按恢复，不填写探索格/地点发现记录 |
| F8 | 开关原有世界地图测试传送；开启后地图左键选择世界格 |
| F9 | 显示角色附近实时原生寻路格：绿=空格，红=当前阻挡 |
| F10 | N1新素材与原开发底图对比，仅影响显示 |
| F11 | 岸院→钟屋→暗渠→灰堤外院→雇工棚→绞盘→旧渠侧间→采石场→岸院 |
| Shift+F11 | 从上述巡览场景返回首次巡览出发点 |

巡览在战斗、死亡、地牢、对话、地图界面、转场和回合锁期间拒绝。临时门继承原门 Alarm 7，原生事件4保存地点；不直接调用 `room_goto`、不搬动已创建玩家。记录的 `EAO_N1_origin_*` 仅是返程导航；不写阶段、解法、证据、人物离场、金币或任务奖励。

观察面板只在本次游戏进程内保留。世界地图雾层隐藏不等于该地区已探索，未发现图标仍可能不显示；地表单位的原生可见性和AI规则保持。F6与F8是独立开关，离开开发测试时分别关闭。

面板显示版本、房间名、角色格坐标、世界格和F7/F9/F10状态；附近门还显示摆放格、原生 grid、门锁、Alarm 7、玩家回合锁与目标 tag，全部只读。它随角色定位并限制在房间范围内，查看遮挡区域时可按 F5 隐藏面板。

0.3.10 增加附近门的实际鼠标 bbox（相对门坐标）和原生 pointed 对象名。七处 N2 阶口的鼠标矩形对齐现有阶口图的可见范围；Sprite 仍是居中原生锚点，保留原生 grid、鼠标处理、寻路和转场。原生左键处理会避开人物，所以检查入口时先指向可见的侧边翻板，等待指向更新后点击；站在阶口中央时点人物身体不作为有效门点击。不能以重复点击次数或面板锁为零认定门已成功转场，须看实际房间和到达坐标。实测结果单独记于 `research/art-door-hit-0310-20261015.md`。

0.3.11 外院、N1/石场竖门与 N2 阶口门名改为原生鼠标指向时显示；外院名称移到门上方，文字与玩家 bbox 相交时向上避让。三处外院文字在 Draw End 绘制以避开建筑立面覆盖，原 Draw 仍继承原生高亮，门的深度与输入顺序保持。永久入口图与原生高亮仍正常绘制，F7 揭雾及其他观察开关保持原义。只读诊断面板仍可在附近显示门坐标，实测范围见 `research/art-door-label-0311-20261015.md`。

0.3.12 五个 N1 场内门分别使用低矮堤道石阶、钟屋木门槛、暗渠阶口，绘制在人物下方；Sprite 原生锚点与实际可见范围的独立 Mask 分开。阶口在普通模式也显示，N1 地面/背景原有的观察开关不变；观察模式中 F10 关闭新素材可看原门板，命中矩形和原生门行为保持。未改门锁或剧情前置，暗渠锁门不得为素材测试而强行开锁。运行覆盖见 `research/art-n1-doorways-0312-20261015.md`。

0.3.13 将 N1 地面、墙沿和原有独立道具素材接入普通游戏显示：无需开启 F6；开启观察后 F10 仍可比较原开发底图，F6 关闭会恢复新场景材质。石场保留原观察开关。N1 三场地面改用完整连续石/木材质，按原可走区裁出，不再镜像小块场景截图；墙沿使用已有原创石条并限制在可走区外，不新增墙体碰撞或入口。导出为 `tools/Export-N1SurfaceRepair.py`（在基础 N1 导出之后运行），原图与提示词在 `src/Art/scene-style-repairs-20261015/n1-surfaces-v1/`；候选检查逐像素对照内嵌地面/墙沿与真实碰撞实例。实机范围见 `research/art-n1-surfaces-0313-20261015.md`。

0.3.14 为钟屋木厅、石廊和暗渠补两格高北墙，侧柱/前沿使用对应木构与石砌材料；清除暗渠旧 backing 水纹碎片。`tools/Export-N1Architecture.py` 在连续地面导出后运行，素材与完整提示词见 `src/Art/scene-style-repairs-20261015/n1-architecture-v1/`。墙面 alpha 仍裁在原阻挡区；候选另核对三场 floor PNG 保持、实际北墙覆盖和暗渠 backing 全画布均匀。该修复不增加碰撞或陈设交互，运行结果单独记于 `research/art-n1-architecture-0314-20261015.md`。

加载角色或重建角色数据时观察模式恢复关闭（0.3.6 仍实测返回地表会出现）；需要继续观察时再按 F6。Shift+F11 已实测回到本次出发位置，返回后的自动恢复仍列待办，见 `research/art-runtime-todo-20261015.md`。F8只核验落点可通行，不保证目标世界格没有敌人；实测重载土匪营地会落到营地内并触发敌人警觉。

当前 51 个 HD2D 精灵覆盖 N1、N2、外院、采石场和道具，生产 PNG 作为程序集资源内嵌到 .sml。尺寸、原点与 PNG 字节对照各素材 manifest 逐项校验，不依赖项目绝对路径。0.3.7 另增复用原图帧的门锚点精灵，不计作新 HD2D 素材。钟屋外观暂在面板中作为独立样件显示，其入口与占地尚未安装到岸院；0.3.8 已下移样件，实机确认不再遮住诊断行。

0.3.7 已实测外院→绞盘室→外院 (26,16)，以及雇工棚→外院。门锚点修正仅覆盖 SceneAssembly 的八个门对象；旧 N1 门未纳入。人物站在门格时仍观察到中心点击优先选中人物/不转场，不能声称点击体验全部解决。旧渠入口已进入，新增侧间外院出口未测。详见 `research/art-scene-door-037-20261015.md`。

0.3.8 更新三处 N2 场景材质，七个门口用低矮阶口图在人物下方绘制，门名改为接近/指向显示；另外四个旧 N2 连接门使用中心锚点。F10 关闭新材质时仍用原开发底图与原生竖门板；本次并未改写真实楼层或攀爬机制。已实测三处新材质、雇工棚回外院 (10,16)、侧间新增 (8,22) 门经普通交互回外院 (42,16)，以及返回原生野外保存退出。逐门站格遮挡、旧室内路线与跨进程重载仍未完成，详见 `research/art-interior-style-038-20261015.md`。

实测发现铺盖新图与继承的原点击区域未对齐；检查交互时可按F10切回原图。这一批用于实机观察，仍需逐物件完成热点、遮挡与碰撞装配。未接N1时查看铺盖曾无法退出，已补“先离开这里”并实测关闭对话。

自动化复测中一次Shift+F11短脉冲被识别为普通F11，随后从岸院重发组合键成功返程。建议先按住Shift再按F11；组合键持续按压还需人工复核，记录不把每次输入均稳定视为已通过。

构建：`tools/Build-Mod.ps1`；部署：`tools/Build-Mod.ps1 -Deploy`。部署要求全部套件与候选SHA一致，并备份data.win、MSL设置、旧包及完整用户数据；游戏或MSL运行时拒绝替换。回滚不自动还原角色存档。

0.3.9 用整段含岸沿水槽替换小水片平铺，既有三个铺盖替换为窄幅俯视草席/毛毯；不新增休息功能或碰撞。素材变更后先运行 `tools/Export-N2InteriorStyleRepair.py`，再依次运行 `tools/Validate-Hd2dNativeN2.py`、`tools/Validate-N2SceneAssembly.py`、`tools/Validate-N2WaterStyleRepair.py`。部署额外核对水槽报告对应当前素材 manifest，候选再核对内嵌 PNG 字节。实机状态见 `research/art-water-bedroll-039-20261015.md`。

本轮不把美术观察当作N1剧情全流程验收。所有实机通过项、失败项和未测项单独记录。
