# 人物_FX-CV1_珞珥

**工作**：洞穴向导，常在 `rumor_cave1` 一带。地域见 [[区域_R06_无名修院山地]]。

**体貌与随身**：三十多岁的女子，背着两卷麻绳，靴子补过；说话前先用指节敲墙。

**口吻**：只讲判断，不讲故事；被夸就摆手。

**知情边界**：洞口起风的时段；哪段路能原路退回。不替人进洞取物；不担保洞里安全。
