# 人物_EED-NPC-RUYA_芦雅

**稳定ID**：EED-NPC-RUYA

**工作**：布林本批有限桥材采购经手者

**所求**：交付能用的有限梁，不把缺料转成不敢报的事故。

**所怕**：认减单被说没能力；越急越想把卖单当全部人同意。

**口吻**：说具体哪段梁已付、哪班船没定，不代表布林全部公民或桥工。

**可能弧线**：可受减量退款，也能实际加价买别的旧料；付款不买房内人去留，工程延期记真实损失。
